# Modality Trajectory — Quick Reference

## The analog engine

```
modality-lifecycle      → P(modality deliverable)   [delivery is the binding constraint]
moa-analog-engine       → arc-position + nearest analog + ignition trial to watch
target-validation-ladder→ P(biology holds)          [human-genetics, causal + direction-of-effect]
        ↓ synthesize
frontier-conviction-scorer → score = P(biology) × P(modality) × arc-position × timing
        ↓ when clinical asset + indication exist
hand off → probability-of-success/pos-calculator + asset-valuation/rnpv-modeler
```

## The MOA arc (the spine)

`target ID → tool/platform → first-in-human → first approval → class explosion → maturity`
- **Time constant:** ~18–30 yr target→first approval (PCSK9 ~12 fastest, KRAS ~39 slowest, PROTAC ~24); then **2–5 yr** explosion.
- **Ignition event:** one hard-endpoint pivotal readout in a genetically/biomarker-defined population (KEYNOTE-024, FOURIER, ELIANA, SELECT, CodeBreaK 100, CLARITY-AD, VERITAC-2).
- **Three sub-patterns:** undruggable-cracking · indication-creep · generational resistance-ladder.

## Routing cheat-sheet

| If the user asks… | Route to |
|---|---|
| "Is the modality ready / delivery problem?" | modality-lifecycle |
| "What's the analog / where on the arc / what trial to watch?" | moa-analog-engine |
| "How validated is the target / genetic support?" | target-validation-ladder |
| "What's my conviction / early PoS?" | frontier-conviction-scorer |
| "Place, grade, and score this candidate" | all four → frontier-conviction-scorer |

## Doctrine (load-bearing)

- Conviction is **gated by the weaker term** (right target + undeliverable modality = waiting game).
- Genetic support with direction-of-effect concordance ≈ **2.6× relative success** (strongest pre-clinical predictor).
- **Marquee failure + modality re-engineering = BUY signal**, not a kill (anti-amyloid, ADCs, siRNA-via-GalNAc).
- Anchor magnitude to **base rates**; never let the analog license de novo optimism.
- The score is qualitative/discovery-stage; **hand off to rNPV/PoS** once a clinical asset + indication exist.

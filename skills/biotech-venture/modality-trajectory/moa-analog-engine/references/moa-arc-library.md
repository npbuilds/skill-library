# MOA Arc Library — Twelve Validated Mechanism-Class Life-Cycles

The reference corpus the analog engine matches candidates against. Each profile gives the **key dates** (target ID / first program / first approval / # in class now), the **time constant**, the **enabling unlock**, the **ignition trial**, the **false starts**, and the **early leading indicators** that, in hindsight, predicted the explosion.

Match a candidate on the **mechanism of unlock**, not the indication. A class is unlocked only when three locks align: validated biology, a modality that can drug it, and a de-risking pivotal readout. Spot-verify load-bearing dates/specifics — sourced from 2024-2026 literature, agent-synthesized.

## ARC 1 — PD-1 / PD-L1 checkpoint inhibition

| | |
|---|---|
| Target ID | 1992 PD-1 cloned (Honjo, Kyoto); PD-L1 1999-2000 (Chen, Freeman) |
| First program (FIH) | 2006 anti-PD-1 (MDX-1106/nivolumab) Phase 1 |
| First approval | **2014** pembrolizumab (Sept) + nivolumab (Dec), melanoma |
| # in class now | ~8-10 agents (PD-1: pembro, nivo, cemiplimab, dostarlimab, retifanlimab; PD-L1: atezo, durva, avelumab), >100 indications |

- **Time constant:** target→approval ≈ **22 yr**; first→explosion ≈ **2 yr**.
- **Enabling unlock:** Honjo/Chen mechanistic biology; the melanoma **durable-response tail** reframed the endpoint conversation; KEYNOTE-024 proved chemo could be displaced in 1L.
- **Ignition trial:** **KEYNOTE-024** (1L NSCLC, PD-L1≥50%, 2016), preceded by KEYNOTE-006 (vs ipilimumab).
- **False starts:** tremelimumab (anti-CTLA-4) Phase 3 failure in melanoma (2008) seeded IO skepticism; PD-L1 as a biomarker proved messy (assay fragmentation).
- **Leading indicators:** the **durable-response tail** — a survival-curve plateau even in heavily pretreated melanoma — was the tell this was a different kind of drug.
- **Maturity move:** **2025** first subcutaneous PD-1: SC nivolumab + **Keytruda Qlex** (SC pembrolizumab, Sept 19 2025, 1-2 min injection vs 30-min IV).

## ARC 2 — GLP-1 receptor agonists (incretin → obesity)

| | |
|---|---|
| Target biology | 1980s incretin effect (Holst, Habener); exendin-4 from Gila monster (Eng, 1992) |
| First approval | **2005** exenatide (Byetta), T2D, BID |
| Obesity unlock | **2021** semaglutide 2.4 mg (Wegovy), STEP, ~15% weight loss |
| # in class now | sema, liraglutide, dulaglutide, tirzepatide (GIP/GLP-1); + oral orforglipron, triple-agonist retatrutide, CagriSema in late stage |

- **Time constant:** target→first approval ≈ **20-23 yr**; first→obesity explosion ≈ **16 yr** (slow — obesity was an unloved indication until the magnitude of effect became undeniable).
- **Enabling unlock:** peptide engineering for half-life (albumin binding → once-weekly); the obesity unlock was *dose* — pushing exposure high enough for double-digit weight loss; SELECT created reimbursement.
- **Ignition trial:** **SELECT** (2023) — semaglutide cut MACE 20% in non-diabetic obesity; flipped obesity from cosmetic to cardiometabolic. (Preceded by STEP/SURMOUNT weight-loss readouts.)
- **False starts:** prior anti-obesity drugs (rimonabant withdrawn 2008, fen-phen) had poisoned the category; GLP-1 overcame the "diet drugs are dangerous" prior.
- **Leading indicators:** **dose-dependent weight loss visible in T2D trials a decade early** — clinicians saw weight loss on Victoza/Ozempic long before the obesity label. The archetypal **indication-creep** pattern.
- **2025 frontier / maturity:** oral orforglipron (ATTAIN-1, ~12.4% weight loss, no food/water restriction); triple-agonist retatrutide.

## ARC 3 — PCSK9 inhibition (the speed champion)

| | |
|---|---|
| Gene ID | **2003** PCSK9 GOF in familial hypercholesterolemia (Abifadel/Boileau, Paris) |
| Human validation | **2006** LOF carriers (Cohen/Hobbs, Dallas Heart Study) — low LDL, low CV risk, healthy |
| First approval | **2015** evolocumab (Repatha) + alirocumab (Praluent), mAbs |
| # in class now | 2 mAbs + inclisiran (siRNA, 2021) + oral enlicitide (MK-0616, Phase 3 2025-26) |

- **Time constant:** gene→first approval ≈ **12 yr — the fastest in this library.**
- **Why so fast:** a *clean human genetic validation* (healthy LOF carriers with very low LDL) collapsed target risk to near zero; LDL is a validated easily-measured surrogate; the modality (mAb) was off-the-shelf.
- **Ignition trial:** **FOURIER** (evolocumab, 2017) — 15% MACE reduction; ODYSSEY OUTCOMES (alirocumab, 2018).
- **False starts:** the *adjacent* CETP target failed spectacularly (torcetrapib, Pfizer, 2006, increased mortality) — "lower a lipid number" ≠ "improve outcomes." PCSK9 avoided this because the genetics tied the target directly to hard CV events. **This is the canonical biology-failure-kills vs genetics-de-risks contrast.**
- **Leading indicators:** **the existence of healthy human knockouts** — the gold-standard signal for any class: a LOF human phenotype that mirrors the desired drug effect. The genetics-first **speed playbook**.
- **Maturity moves:** cadence (inclisiran twice-yearly, 2021) and route (oral enlicitide, ~2% oral bioavailability, CORALreef Outcomes >14,500).

## ARC 4 — KRAS G12C (the "undruggable" cracking)

| | |
|---|---|
| Oncogene ID | **1982** KRAS identified as a human oncogene |
| The unlock | **2013** Shokat lab (Ostrem et al., *Nature*): G12C cysteine covalently trapped in switch-II pocket |
| First-in-human | **2018** sotorasib (AMG 510) |
| First approval | **2021** sotorasib (Lumakras), NSCLC |
| # in class now | sotorasib + adagrasib (2022); next wave divarasib, pan-RAS(ON) daraxonrasib RMC-6236, G12D zoldonrasib/MRTX1133, G12C elironrasib |

- **Time constant:** oncogene→approval ≈ **39 yr (the slowest)**; tool→approval ≈ **8 yr** (very fast *once the chemistry existed*).
- **Enabling unlock:** a single chemistry insight (covalent trapping of a mutant cysteine) + structure-based design. Biology was validated for decades; the bottleneck was purely **modality**.
- **Ignition trial:** **CodeBreaK 100** (sotorasib, 2021). Jan 2025: sotorasib + panitumumab approved for KRAS G12C colorectal cancer (indication expansion).
- **False starts:** farnesyltransferase inhibitors (1990s, tipifarnib) — an entire failed approach to drugging RAS indirectly; antisense KRAS; the decades-long "RAS is undruggable" dogma.
- **Leading indicators:** the **first co-crystal structure with a covalent ligand** (2013-2016) told the field the index mutation was crackable — and that the platform (covalent + structure) would generalize to G12D, pan-RAS, RAS(ON). The index case of **undruggable-cracking**: the unlock generalizing beyond the index target is the explosion signal.

## ARC 5 — CD19 CAR-T

| | |
|---|---|
| Concept | 1989-1993 Eshhar "T-body"; CD19 as B-cell target |
| 2nd-gen CAR (costim) | 2002-2009 June, Sadelain, Brentjens — CD28/4-1BB domains made CARs persist |
| First approval | **2017** tisagenlecleucel (Kymriah, ALL) + axi-cel (Yescarta, LBCL) |
| # in class now | **6 FDA products** (CD19: Kymriah, Yescarta, Tecartus, Breyanzi; BCMA: Abecma, Carvykti) |

- **Time constant:** concept→approval ≈ **25+ yr**; first→explosion ≈ **2-3 yr**.
- **Enabling unlock:** the **costimulatory domain** (2nd-gen CAR) that let cells persist and expand in vivo — without it 1st-gen CARs (1990s) failed.
- **Ignition trial:** **ELIANA / ZUMA-1** (2017), preceded by single-patient cures (Emily Whitehead, 2012).
- **False starts:** 1st-gen CARs that didn't persist; a fatal HER2-CAR case (2010, on-target/off-tumor) that nearly killed solid-tumor CAR enthusiasm; ongoing failure in solid tumors.
- **Leading indicators:** **n-of-1 durable complete responses in terminal disease** (Emily Whitehead, early UPenn CLL patients) — extreme leading indicator.
- **2024-2026 frontier:** **autoimmune** CD19 CAR-T → drug-free remission in refractory SLE (NEJM 2025); **in vivo** CAR generation via tLNP/lentivirus (Capstan CPTX2309, AbbVie ~$2.1B; CREATE) to collapse the ex-vivo manufacturing ceiling. The maturity-phase attempt to escape the cost/manufacturing ceiling — note the class can be re-rated by a *delivery* unlock.

## ARC 6 — siRNA / RNAi and antisense (ASO)

| | |
|---|---|
| Mechanism (RNAi) | **1998** Fire & Mello, *Nature* (Nobel 2006) |
| Delivery solved | 2004-2014 LNP then **GalNAc conjugation** (hepatocyte targeting) |
| First siRNA approval | **2018** patisiran (Onpattro, hATTR), LNP |
| # in class now | **6 siRNA by 2025** (patisiran, givosiran 2019, lumasiran 2020, inclisiran 2021, vutrisiran 2022, nedosiran 2023; + fitusiran/Qfitlia 2025); ~10+ ASOs (nusinersen 2016, olezarsen Dec 2024) |

- **Time constant:** mechanism→durable siRNA class ≈ **20 yr** (the delay was *entirely delivery*); first siRNA→6 approved ≈ **5-7 yr**.
- **Enabling unlock:** **GalNAc conjugation** turned siRNA from an undeliverable idea into a subcutaneous, durable, hepatocyte-targeted platform (inclisiran twice-yearly). For ASO: chemistry (2'-MOE, PS backbone) + intrathecal delivery.
- **Ignition trial / signal:** durable deep knockdown from a single SC dose once GalNAc landed; nusinersen (Spinraza, SMA, 2016) was the ASO breakout.
- **False starts:** the **2006-2010 RNAi hype cycle and crash** — Roche, Novartis, Merck/Sirna all exited ~2010-2011 when delivery failed; Alnylam nearly died. The textbook **modality-failure-then-redemption**.
- **Leading indicators:** durable target knockdown enabling twice-yearly dosing was the tell this would become a chronic-disease platform. The platform fix (GalNAc), not new biology, converted the class.
- **Next frontier:** zilebesiran (siRNA for hypertension, Phase 3) — RNAi into chronic common disease; extrahepatic delivery (C16/lipophilic, antibody-siRNA for muscle) is the open frontier.

## ARC 7 — Antibody-drug conjugates (ADCs)

| | |
|---|---|
| Concept | 1980s-1990s "magic bullet" — antibody + cytotoxin |
| First approval | **2000** gemtuzumab ozogamicin (Mylotarg, AML) — **withdrawn 2010**, re-approved 2017 at lower dose |
| Redemption readout | **2019-2022** trastuzumab deruxtecan (Enhertu, T-DXd), DESTINY-Breast |
| # in class now | ~15 FDA / ~19-21 global (+ sacituzumab govitecan, enfortumab vedotin; 2025 adds datopotamab deruxtecan, telisotuzumab vedotin) |

- **Time constant:** concept→durable class ≈ **20+ yr**; the *real* explosion dates from T-DXd (2019), not the 2000 first approval.
- **Enabling unlock:** **linker/payload engineering** — stable linkers, controlled drug-antibody ratio, membrane-permeable payloads (DXd) enabling the bystander effect. Biology (target antigen) was never the bottleneck; conjugation chemistry was.
- **Ignition trial:** **DESTINY-Breast** (T-DXd, 2019-2022) — created the "HER2-low" category.
- **False starts:** Mylotarg's 2010 withdrawal nearly killed the class; multiple first-gen ADCs failed on linker instability (premature payload release → toxicity).
- **Leading indicators:** **T-DXd activity in HER2-LOW tumors** — efficacy in a population the target "shouldn't" reach signaled the bystander mechanism worked, making ADCs a broad platform not a niche. The **off-target-population efficacy** signal.

## ARC 8 — PROTACs / molecular-glue degraders

| | |
|---|---|
| Concept | **2001** Crews & Deshaies — "Protac" coined |
| Glue precedent | 2010-2014 thalidomide/lenalidomide shown to be molecular-glue degraders (CRBN/IKZF) — proof degradation works clinically |
| First-in-human PROTAC | **2019** ARV-110 (bavdegalutamide, AR) + ARV-471 (vepdegestrant, ER) |
| First approval | **2025** **vepdegestrant (VEPPANU, Arvinas/Pfizer)** — ESR1-mutant ER+/HER2– breast cancer |
| # in class now | 1 approved; deep pipeline (BTK degraders, IRAK4, STAT3, KRAS degraders; glues for undruggable TFs — VAV1, MYC/MYCN) |

- **Time constant:** concept→first approval ≈ **24 yr**; class is *just entering* Phase 4 now.
- **Enabling unlock:** (1) retrospective discovery that lenalidomide was already a validated clinical glue de-risked degradation; (2) ternary-complex structural biology + E3-ligase ligand discovery (CRBN, VHL); (3) event-driven (catalytic, sub-stoichiometric) pharmacology drugs targets inhibitors can't.
- **Ignition trial:** **VERITAC-2** (vepdegestrant, 2025) — mPFS 5.0 vs 2.1 mo vs fulvestrant in ESR1m.
- **False starts:** early PROTACs had terrible drug-like properties (huge MW, poor oral PK); many programs stalled on bioavailability.
- **Leading indicators:** **oral bioavailability + clean human PK for a bivalent degrader** (ARV-471) — once a PROTAC behaved like a real oral drug, the "rule-of-5 violation kills degraders" fear dissolved. Sub-pattern overlap: degraders are *the* unlock for the **undruggable-cracking** of flat-surface/disordered targets.

## ARC 9 — Complement (C5 / factor B / factor D / C3)

| | |
|---|---|
| Pathway biology | 1970s-1990s complement cascade; C5 as terminal effector |
| First approval | **2007** eculizumab (Soliris, anti-C5), PNH → aHUS, gMG, NMOSD |
| Second wave | **2021-2024** pegcetacoplan (C3, 2021); iptacopan (factor B, oral, Dec 2023); danicopan (factor D, oral add-on, Apr 2024); crovalimab (C5, 2024) |
| # in class now | ~5+ agents across C5/C3/factor B/factor D; expanding into geographic atrophy, IgA nephropathy |

- **Time constant:** pathway→first approval ≈ long/diffuse; first→class re-ignition ≈ **~14 yr** (a slow-burn class; eculizumab was essentially alone 2007-2018).
- **Enabling unlock (second wave):** **oral proximal inhibition** (factor B/D) addressing residual **extravascular hemolysis** patients still had on C5 blockade.
- **Ignition signal:** persistent anemia/EVH in eculizumab responders — a *clinical unmet need inside a treated population*.
- **False starts:** complement considered too central/redundant to inhibit safely for decades; meningococcal infection risk gated adoption.
- **Leading indicators:** **a clear unmet need inside an already-treated population** reliably predicts a next-gen sub-class will form. The **unmet-need-wedge** template.

## ARC 10 — Anti-amyloid (Aβ) in Alzheimer's

| | |
|---|---|
| Hypothesis | **1991-1992** amyloid cascade (Hardy & Higgins) |
| Genetic validation | 1990s-2012 APP/PSEN mutations; protective A673T variant (2012) |
| First replicated efficacy | **2023** lecanemab (Leqembi), CLARITY-AD, ~27% slowing, full approval July 2023 |
| # in class now | lecanemab + donanemab (Kisunla, July 2024, TRAILBLAZER-ALZ2); next-gen trontinemab (Roche Brainshuttle, Phase 3 launched Sept 2025) |

- **Time constant:** hypothesis→first replicated drug ≈ **31-32 yr** (one of the longest, with a brutal failure record).
- **Enabling unlock:** **protofibril/aggregated-species selectivity** (lecanemab targets soluble protofibrils) + amyloid-PET to enrich for amyloid-positive patients + p-tau biomarkers. The hypothesis was right; earlier drugs hit the wrong species or stage.
- **Ignition trial:** **CLARITY-AD** (lecanemab, 2023); confirmed by TRAILBLAZER-ALZ2 (donanemab, 2024).
- **False starts (the long winter):** semagacestat (γ-secretase, 2010, *worsened* cognition); bapineuzumab (2012); solanezumab (2016); verubecestat/BACE failures; contested aducanumab (2021, withdrawn 2024). **The most failure-laden class here.**
- **Leading indicators:** **dose-dependent plaque clearance that tracked with a small clinical slowing in the right patients** (lecanemab Phase 2b) — once clearance and benefit moved together, the class became investable. **The index case of false-start-as-penultimate-stage:** γ-secretase/BACE were *biology/stage* failures (avoid), but the antibody-species/dosing failures were *modality* failures that were re-engineered (titration to cut ARIA; BBB-shuttle trontinemab, ARIA-E <5% vs 13% lecanemab / 24% donanemab).
- **Maturity moves (2025):** lecanemab SC (Leqembi IqLik) + every-4-week maintenance; donanemab titration relabel to cut ARIA-E.

## ARC 11 — IL-23 / IL-17 in immunology

| | |
|---|---|
| Pathway dissection | 2000-2007 IL-23 (not IL-12) drives pathogenic Th17 axis; IL-17 as effector |
| First IL-17 approval | **2015** secukinumab (Cosentyx, psoriasis); ixekizumab 2016 |
| First selective IL-23p19 | **2017** guselkumab (Tremfya); risankizumab 2019, tildrakizumab 2018 |
| # in class now | IL-17 (secu, ixe, dual IL-17A/F bimekizumab 2023) + IL-23p19 (guselkumab, risankizumab, tildrakizumab), expanding into PsA, axSpA, IBD |

- **Time constant:** pathway→first approval ≈ **8-15 yr**; first→explosion ≈ **2-4 yr** (two adjacent sub-classes formed nearly simultaneously).
- **Enabling unlock:** the **IL-12/23 → IL-23-specific dissection** — realizing the p19 subunit (not shared p40) was the disease driver let companies build cleaner, more durable agents.
- **Ignition signal:** rising PASI-100 (complete skin clearance) + durability in head-to-head psoriasis trials.
- **False starts:** broad IL-12/23 (ustekinumab, p40) was good but not optimal; some IL-17 agents flagged IBD-worsening (a mechanism-specific safety signal that *redirected* the class toward IL-23 for gut indications).
- **Leading indicators:** **a rising efficacy ceiling (PASI-100) + durability** signaled room for multiple winners and indication expansion. The **pathway-dissection** template: one pathway spawns adjacent cleaner sub-classes.

## ARC 12 — BTK inhibition

| | |
|---|---|
| Target biology | 1993 BTK identified (X-linked agammaglobulinemia gene) |
| 1st-gen covalent | **2013** ibrutinib (Imbruvica), MCL/CLL |
| 2nd-gen cleaner covalent | 2017-2019 acalabrutinib (2017), zanubrutinib (2019) |
| 3rd-gen non-covalent | **2023** pirtobrutinib (Jaypirca) — beats C481S resistance |
| # in class now / 4th-gen | + BTK degraders 2024-2026 (bexobrutideg/NX-5948, Nurix — CNS-penetrant, FDA fast track 2024) |

- **Time constant:** target→first approval ≈ **20 yr**; first→full generational ladder ≈ **~12 yr** and still extending.
- **Enabling unlock per rung:** each generation triggered by a **defined resistance or tolerability problem** — ibrutinib off-target AEs (afib, bleeding) → cleaner covalent; the **C481S** mutation (destroys covalent binding) → non-covalent pirtobrutinib; resistance to *all* inhibitors + CNS disease → degraders.
- **Ignition signal:** ibrutinib's dramatic CLL/MCL responses validated the target; each subsequent rung was validated by activity in the prior generation's resistant population.
- **False starts:** few outright failures; instead a steady ladder where each agent's *limitation* defined the next.
- **Leading indicators:** **the recurrent C481S resistance mutation** — a single dominant escape mechanism is a near-perfect predictor that a next sub-class (non-covalent, then degraders) will form. The index case of the **generational resistance-ladder**: the resistance mutation IS the leading indicator of the next sub-class.

## Cross-arc synthesis (how to use the library)

### Recurring transitions and rate-limiters

| Transition | Median | Range | Rate-limiter |
|---|---|---|---|
| Target ID → first tool compound | 3-8 yr | 1 (PCSK9) – 31 (KRAS) | Modality/druggability |
| Tool → first-in-human | 3-7 yr | — | Tox/PK |
| First-in-human → first approval | 5-9 yr | 3-8 | Pivotal trial design |
| **Target ID → first approval** | **~18-25 yr** | **12 (PCSK9) – 39 (KRAS)** | Slowest of modality/validation/biology |
| **First approval → class explosion** | **2-5 yr** | 2-7 | Capital reallocation speed |
| Explosion → maturity (oral/SC/biosimilar) | 5-15 yr | — | Competitive saturation |

### The diagnostic role of false starts

A high-profile failure is **not** disqualifying — it is often the *penultimate* stage. The discriminating question: **was the failure in the biology or in the modality/execution?**
- **Biology failures kill classes:** CETP raising mortality (no genetic tie to outcomes); BACE/γ-secretase worsening cognition (confirmed mechanism harm).
- **Modality/execution failures are re-engineerable:** bad linker (1st-gen ADC), bad delivery (pre-GalNAc siRNA), bad oral PK (early PROTAC), wrong amyloid species/dose. **The class that returns with the fix is the one that explodes** — anti-amyloid, ADC, siRNA all proved it.

### 2024-2026 as a generation of "firsts" (where to point the engine now)

- **First PROTAC approval** (vepdegestrant, 2025) — degraders entering Phase 4. Watch BTK/IRAK4/KRAS degraders next.
- **Oral GLP-1 and oral PCSK9 Phase 3 wins** (orforglipron; enlicitide) — maturity-phase route innovation for two already-exploded classes.
- **Subcutaneous PD-1** (Keytruda Qlex) — commodity-maturity convenience play.
- **In vivo and autoimmune CAR-T** — breaking the ex-vivo manufacturing ceiling and opening a vastly larger non-oncology market.
- **BBB-penetrant antibodies** (trontinemab) and **brain-penetrant degraders** (bexobrutideg) — the CNS-delivery unlock that could re-rate neuro classes the way GalNAc re-rated siRNA.

### Data sources to refresh an arc

ClinicalTrials.gov v2 (trial counts, phase, enrollment, primary completion — CORALreef, VERITAC-2, TRONTIER 1/2, ATTAIN, CodeBreaK), ChEMBL (target IDs, MOA, IC50/Ki for tool compounds), PubMed/MEDLINE (Ostrem 2013, Fire & Mello 1998, CLARITY-AD, FOURIER, SELECT), bioRxiv/medRxiv (in vivo CAR-T, next-gen degraders), Consensus (efficacy/safety evidence synthesis), Open Targets (target-disease genetic validation), FDA Drugs@FDA (first-approval dates, SC/oral reformulations), DrugBank/AdisInsight (first-in-class chronology), company investor releases (pivotal readouts), ASCO/ASH/CTAD/AHA congress abstracts (latest 2024-2026 readouts).

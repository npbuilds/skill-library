# Frontier Intelligence — Quick Reference

## The radar pipeline

```
signal-scanner      → velocity (2nd derivative of literature/preprint/patent/grant + first-IND)
data-generation-monitor → substrate data (pQTL/MR, DepMap, Perturb-seq, biobanks) by orthogonal convergence
mindshare-tracker   → attention (0–100 momentum, reflexivity + anti-hype gate)
        ↓ fuse
emerging-target-radar → ranked watchlist (lead-time + NewCo + pattern tags)
        ↓ hand off
modality-trajectory (analog engine)
```

## Routing cheat-sheet

| If the user asks… | Route to |
|---|---|
| "Is interest accelerating / when did this get hot?" | signal-scanner |
| "Is this hype or real / how overheated?" | mindshare-tracker |
| "A new dataset/screen/biobank dropped — what does it imply?" | data-generation-monitor |
| "What should I be tracking / rank the emerging bets" | emerging-target-radar |
| "Real momentum or manufactured?" | signal-scanner → mindshare-tracker |
| "Full frontier scan → watchlist" | all four → emerging-target-radar |

## Anti-hype discipline (load-bearing)

- Read **acceleration**, not volume. Strip review/perspective types. Subtract single-lab artifacts (author Herfindahl).
- **Data > attention.** Mindshare without orthogonal data convergence = reflexive froth.
- Reflexivity is **structural**: capital manufactures the attention it claims to detect → the score is a timing instrument, gated by a Consensus evidence-maturity check.
- Normalize NewCo-formation signal against the financing regime (2025 was contractionary).

# Aesthetic Evolution Log

Timestamped record of profile changes. Each entry captures what changed, why (evidence), and the resulting profile shift.

---

## Format

```
## [DATE] — [CHANGE TYPE]

**Trigger:** [what caused this update]
**Dimensions affected:**
- [Dimension]: [old position] → [new position] (confidence: [old] → [new])
**Evidence:** [specific outputs or patterns that drove the change]
**Notes:** [optional context — was this gradual drift or intentional pivot?]
```

**Change types:**
- `drift` — gradual shift from accumulated outputs
- `reinforcement` — existing tendency confirmed by new data
- `pivot` — user deliberately moved in a new direction
- `discovery` — new dimension proposed from observed pattern
- `decay` — dimension losing confidence due to inactivity

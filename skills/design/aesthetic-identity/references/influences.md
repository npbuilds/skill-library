- Type: movement
- First referenced: 2026-03-28
- Frequency: 1
- What it signals: Temporal Register → retro-futuristic, Precision → mechanical, Geometry → geometric, Temperature → cool
- Key qualities: Not pristine neon cyberpunk — the user specifically wants the *aged* version. "Lived in." Faded neon, CRT artifacts, worn textures. Think Blade Runner 2049's muted palette more than Akira's vivid saturation. The grime and patina matter as much as the futurism.

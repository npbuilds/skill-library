## Photography Genres — Dimensional Signatures

The user's stated genre interests, mapped to typical dimensional ranges.

### Street / Documentary
The built environment observed candidly. Grit, texture, decisive moments, environmental storytelling.

| Dimension | Typical Range | Notes |
|-----------|:-:|---|
| Substrate/Grain | 0.50–0.75 | Often grainy — film or high ISO. Texture = authenticity. |
| Atmosphere/Mood | 0.50–0.80 | Moody by default. Weather, shadow, time of day matter. |
| Precision | 0.40–0.60 | Neither pixel-perfect nor painterly. Captured, not constructed. |
| Emotional Register | 0.20–0.35 | Serious. Documentary gravitas. |
| Geometry | 0.20–0.40 | Urban geometry provides structure. Not organic. |
| Light Character | 0.40–0.80 | Wide range — available light determines, not photographer. |
| Depth | 0.50–0.70 | Environmental depth. Layers of urban space. |

### Architectural / Design
Built environments as aesthetic objects. Precision, geometry, light as material.

| Dimension | Typical Range | Notes |
|-----------|:-:|---|
| Geometry | 0.10–0.25 | Strongly geometric. Lines, planes, angles. |
| Precision | 0.10–0.30 | Mechanical precision. Straight verticals, sharp focus. |
| Light Character | 0.55–0.85 | Directional light reveals form. Side-light on facades. |
| Symmetry | 0.25–0.45 | Often symmetric or deliberately asymmetric. |
| Depth | 0.55–0.75 | Perspective lines, receding planes, spatial depth. |
| Atmosphere/Mood | 0.30–0.60 | Varies — clear for documentation, moody for editorial. |
| Density | 0.40–0.70 | Can be minimal (single structure) or complex (urban fabric). |

### Cinematic / Editorial
Styled compositions with dramatic intent. Color-graded, narrative framing.

| Dimension | Typical Range | Notes |
|-----------|:-:|---|
| Light Character | 0.65–0.90 | Hard, directional, dramatic. Controlled or selected. |
| Atmosphere/Mood | 0.60–0.85 | Moody, dramatic. Atmosphere is the subject. |
| Contrast | 0.55–0.75 | Bold. Crushed blacks, lifted highlights, or both. |
| Depth | 0.60–0.80 | Layered. Foreground/midground/background separation. |
| Substrate/Grain | 0.40–0.70 | Often graded to look like film. Digital mimicking analog. |
| Temperature | 0.30–0.70 | Color graded — teal/orange, cool desaturation, warm amber. |
| Sublime Scale | 0.40–0.80 | Can be intimate or vast. Scale is a deliberate choice. |

## Anti-Interests

These genres are explicitly **excluded** as signal sources for the aesthetic profile. If the user shares an image from one of these categories, Tengan should note it but NOT weight it toward profile updates unless the user explicitly signals otherwise.

- **Nature / Landscape** — Sunsets, mountains, flowers, wildlife. Not a signal source.
- **Fashion** — Runway, editorial fashion, outfit photography. Not a signal source.
- **Portraits** — Headshots, studio portraits, environmental portraits of people. Not a signal source.

*Rationale: The user's stated interests are street, architectural, and cinematic/editorial. These anti-interests prevent the profile from drifting toward genres the user encounters but doesn't aesthetically identify with.*

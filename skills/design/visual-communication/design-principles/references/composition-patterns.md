# Composition Patterns

Reusable spatial arrangements for common design situations.

## Pattern 1: F-Pattern (Content Pages)

The eye scans in an F-shape on text-heavy pages:
1. Horizontal sweep across the top
2. Drop down, shorter horizontal sweep
3. Vertical scan down the left edge

**Use for:** articles, blog posts, search results, documentation
**Place key content:** top-left area, first two lines, left column
**Avoid:** important content in the bottom-right — it gets the least attention

## Pattern 2: Z-Pattern (Landing Pages)

The eye follows a Z on minimal pages with few elements:
1. Top-left to top-right (header/nav)
2. Diagonal to bottom-left
3. Bottom-left to bottom-right (CTA)

**Use for:** landing pages, hero sections, marketing pages
**Place CTA:** bottom-right of the Z — the natural endpoint

## Pattern 3: Center Stage (Hero/Feature)

Single dominant element centered with supporting content orbiting.

**Use for:** product showcases, app store listings, hero images
**Key rule:** the center element must have massive contrast with everything else

## Pattern 4: Card Grid (Collections)

Equal-weight elements in a regular grid. Each card is self-contained.

**Use for:** product catalogs, portfolios, team pages, dashboards
**Key rule:** every card follows identical internal structure — consistency is everything
**Variation:** masonry (variable height) for visual interest, fixed grid for scanability

## Pattern 5: Split Screen (Comparison/Dual Focus)

Vertical divide, two equal halves, often with contrasting content.

**Use for:** before/after, two options, image+text pairing
**Key rule:** the dividing line must feel intentional, not accidental

## Pattern 6: Asymmetric Sidebar (Dashboard/App)

Narrow fixed sidebar + wide content area. The sidebar anchors navigation.

**Use for:** applications, dashboards, admin panels, documentation sites
**Key rule:** sidebar width should be 200-300px max — it's navigation, not content

## Pattern 7: Stacked Sections (Long-Form)

Full-width sections stacked vertically, alternating visual treatment.

**Use for:** marketing sites, case studies, long-form storytelling
**Key rule:** alternate background color or density between sections to create rhythm
**Variation:** alternating image-left/image-right within sections

## Pattern 8: Golden Ratio Spiral

Place the focal point at the spiral's center (approximately 1/3 from edges). Arrange supporting elements along the spiral path.

**Use for:** editorial photography, poster design, fine art composition
**Note:** most designers approximate this with rule-of-thirds — close enough for practical use

## Choosing a Pattern

| Content type | Best patterns |
|-------------|--------------|
| Text-heavy, informational | F-pattern, Asymmetric sidebar |
| Marketing, conversion | Z-pattern, Center stage |
| Collections, browsing | Card grid, Stacked sections |
| Comparison, choice | Split screen |
| Narrative, storytelling | Stacked sections, Golden ratio |
| Application, tool | Asymmetric sidebar, Card grid |

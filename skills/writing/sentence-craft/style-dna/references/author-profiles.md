# Author Profiles — Complete DNA

Each author is profiled across all 14 dimensions using a 1-5 scale per axis.

**Scale key**: 1 = far left of spectrum, 3 = mid, 5 = far right of spectrum. See SKILL.md for dimension definitions.

## The Palette (23 Authors)

### Albert Camus
**Identity**: The flat statement that detonates. Existential clarity achieved through refusal to ornament, explain, or comfort.
**Signature move**: Emotional events delivered in the same register as weather reports. The reader feels the gap.

| Dimension | Score | Note |
|-----------|-------|------|
| Sentence Rhythm | 2 | Low variance — steady, measured beat |
| Psychic Distance | 3.5 | Mid-far — close enough to observe, too far to inhabit |
| Info Density | 2 | Sparse — meaning in the gaps between statements |
| Ornamentation | 1.5 | Austere — figurative language rare and precise when used |
| Narrative Velocity | 3 | Mid — neither rushing nor lingering |
| Lexical Register | 2.5 | Mid-demotic — plain but never slangy |
| Authorial Presence | 1.5 | Invisible but felt through absence — a deliberate flatness |
| Sensory Bandwidth | 2 | Selective — sun, heat, physical sensation as existential fact |
| Emotional Explicitness | 1 | Deeply submerged — the text refuses to name what it makes you feel |
| World-to-Story | 1.5 | Story-dominant — the world is a projection of consciousness |
| Syntactic Complexity | 1.5 | Paratactic — clauses sit beside each other without hierarchy |
| Tonal Stability | 1 | Monotonal — flat affect maintained |
| Dialogic Texture | 2 | Transparent — dialogue is functional |
| Epistemic Stance | 2 | Meaning-uncertain — events are clear, significance is not |

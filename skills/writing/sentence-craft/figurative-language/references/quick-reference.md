# Figurative Language — Quick Reference


## Practitioners

| Author | Strategy | Effect |
|--------|----------|--------|
| Morrison | Metaphor as incantation — rhythmic, accumulating | Mythic register, oral tradition |
| McCarthy | Landscape as metaphor | Environment carries moral weight |
| VanderMeer | Biological metaphor | The "weird" through familiar biology |
| Woolf | Metaphor as consciousness | Interiority and figuration fuse |
| Nabokov | Metaphor as performance | The narrator's skill IS character |

# Narrative Geometry — Quick Reference


## Choosing a Geometry

| Material | Shape |
|----------|-------|
| Journey with tangents | Meander |
| Trauma, obsession, returning | Spiral |
| Single event, many ripples | Radial |
| Pattern repeating at every scale | Fractal |
| Emotional ebb and flow | Wavelet |
| Multiple lives, one theme | Braid |
| Cyclical return | Cycle |
| Emotional flavors over conflict | Rasa |
| Community, ecosystem | Carrier bag |
| Conflict, stakes, climax | Arc (`narrative-arc`) |

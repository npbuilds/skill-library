# Historiography — Quick Reference

## Routing (one-line)

| User signal | Route to |
|---|---|
| "How do we know," "what's the evidence" | source-criticism |
| "How should I think about," "framework for" | historical-thinking |
| "Why do historians disagree," "different interpretations" | schools-of-thought |
| "Is this argument convincing," "how would you prove," "what caused" | historical-argument |
| "Evaluate this source" (specific document in hand) | source-evaluator → source-criticism |
| "How has the study of X changed over time" | schools-of-thought |

## Curriculum Order

```
historical-thinking      [foundation]   The cognitive operating system
       ↓
source-criticism         [core]         Evaluating individual evidence
       ↓
historical-argument      [synthesis]    Constructing and critiquing claims
       ↓
schools-of-thought       [advanced]     Interpretive traditions and stakes
```

`source-evaluator` is an *action* skill — invoked when a specific source is in hand and a structured evaluation template is needed.

## Multi-Skill Sequences

| Question shape | Load order |
|---|---|
| "How do we know X happened?" | source-criticism → historical-argument |
| "Why do schools A and B disagree about Y?" | schools-of-thought → historical-argument |
| "Teach me to think like a historian" | historical-thinking → source-criticism → historical-argument |
| "Evaluate this primary source" | source-evaluator → source-criticism → (historical-argument if argument is also asked) |

## Conflict Resolution

| Conflict | Rule |
|---|---|
| Source vs. tradition | Source wins — but name the tradition's reasoning |
| Two valid frameworks disagree | Present both, name stakes — teach the debate |
| General heuristic vs. specific knowledge | Specific wins for that case |

## Default Stance

**Method before conclusion.** When in doubt, teach the user how to figure it out rather than what to think.

## Escalate to wan-shi-tong when

- Question is about a specific event → thematic wing
- Question applies history to a present decision → applied-history
- Question requires regional expertise → regional-atlas

# Cross-Wing Bridges

Most real historical questions span 2+ wings. This doc maps common question patterns to their primary + supporting cast assignments. Use these when `delegation-rules.md` doesn't surface a clear primary.

## Bridge Patterns by Question Shape

### Pattern 1 — "Why did [Empire/Civilization] fall?"

**Primary:** political-history (collapse of governance is the visible event).
**Supporting (in load order):**
1. economic-history — fiscal exhaustion, currency debasement, trade-route disruption
2. military-history — frontier pressure, mercenary substitution, military overstretch
3. world-systems — climatic stress, plague cycles, demographic collapse
4. historiography — multiple schools always disagree on which factor dominates

**Worked example — fall of Rome:** Gibbon (Christianity / barbarism), Pirenne (Islamic Mediterranean closure), Wickham (transformation, not fall), Ward-Perkins (catastrophic material decline). Always name at least two.

### Pattern 2 — "How did [Technology] change history?"

**Primary:** intellectual-history (ideas about the technology + the knowledge systems it enabled).
**Supporting:**
1. economic-history — production, distribution, who benefited
2. cultural-history — how it reshaped daily life and identity
3. world-systems — whether it was a "civilizational force" (Diamond/Christian sense)
4. military-history — only if the tech was weaponizable (gunpowder, steam, nuclear)

**Worked example — printing press:** intellectual-history primary (knowledge production decentralized) + cultural (vernacular literacy, religious dissent) + economic (book trade) + world-systems (only Europe industrialized this medium — why?).

### Pattern 3 — "Was [Empire/System] good or bad?"

**Primary:** applied-history (this is a normative question seeking present-day judgment).
**Supporting:**
1. The thematic wings supplying the *evidence* the judgment rests on (usually political + economic + cultural)
2. historiography (always — to surface the moral framework being applied)

**Worked example — British Empire:** applied-history frames the question (for whom good? on which timescale?), then political-history (governance), economic-history (extraction vs. development debate), cultural-history (lived experience under colonialism), historiography (Niall Ferguson vs. Shashi Tharoor as named contrast).

### Pattern 4 — "Tell me about [Trade Route / Network]"

**Primary:** economic-history (the underlying logic is exchange).
**Supporting:**
1. cultural-history — religions, technologies, art moving along the route
2. regional-atlas — geographic specifics of nodes and termini
3. world-systems — the network's place in civilizational connectivity

**Worked example — Silk Road:** economic primary (luxury goods, monetary metals) + cultural (Buddhism's eastward spread, Manichaeism, technology transfer) + regional-atlas (Sogdian merchants, Tarim oases) + world-systems (Eurasia as a single circulation system).

### Pattern 5 — "How did [Marginalized Group] resist [System]?"

**Primary:** cultural-history (subaltern agency is the central concern).
**Supporting:**
1. political-history — the formal structures being resisted
2. applied-history — only if the user is drawing forward to present movements
3. historiography — almost always: subaltern history exists because earlier traditions ignored it; name that move

**Worked example — slave revolts in the Atlantic world:** cultural primary (community formation, religion as resistance) + political (legal regimes, abolition movements) + historiography (CLR James, Eric Williams, recent Atlantic history turn).

### Pattern 6 — "What caused [War]?"

**Primary:** political-history (war is politics by other means — Clausewitz).
**Supporting:**
1. military-history — once the war begins, mechanism of escalation
2. economic-history — resource competition, war finance
3. intellectual-history — ideologies that made the war thinkable
4. world-systems — only for very large wars (WW1, WW2) where structural causes dominate

**Worked example — WW1:** political primary (alliance system, Balkan crisis) + military (mobilization timetables) + economic (imperial competition, naval arms race) + intellectual (nationalism, Social Darwinism, war as renewal).

### Pattern 7 — "How did [Religion / Belief System] spread?"

**Primary:** cultural-history (religion-as-lived-practice is cultural).
**Supporting:**
1. intellectual-history — doctrinal content and contestation
2. regional-atlas — geographic vectors of spread
3. economic-history — trade networks as conduits
4. political-history — state sponsorship or persecution

**Worked example — Buddhism's spread:** cultural primary (devotional practice, monasticism) + intellectual (sutras, Mahayana split) + regional-atlas (Silk Road nodes, maritime routes) + economic (merchant patronage) + political (Ashoka, Tang court).

### Pattern 8 — "Why did [Region] industrialize first / later?"

**Primary:** economic-history (the dependent variable is industrial output).
**Supporting:**
1. world-systems — the Great Divergence debate (Pomeranz, Allen)
2. regional-atlas — local resource and institutional context
3. intellectual-history — Scientific Revolution, Enlightenment knowledge regimes
4. political-history — fiscal-military state capacity

**Worked example — Great Divergence:** economic primary (coal, capital, wages) + world-systems (Pomeranz: contingent on coal location and New World resources) + regional-atlas (Yangzi Delta vs. Lancashire) + intellectual (whether Scientific Revolution was necessary or epiphenomenal).

### Pattern 9 — "Compare [Civilization A] and [Civilization B]"

**Primary:** world-systems (comparison across civilizations is its native register).
**Supporting:**
1. regional-atlas (×2) — both regions' specifics
2. The thematic wing relevant to the comparison axis (economic, political, intellectual, military)

**Worked example — Han vs. Roman:** world-systems primary (comparative civilizations as analytical frame) + regional-atlas (Mediterranean, East Asia) + political (imperial governance models) + economic (silver flows linking the two).

### Pattern 10 — "How do historians disagree about [Event]?"

**Primary:** historiography.
**Supporting:**
1. The thematic wing for the event's *content*
2. intellectual-history — only if the disagreement reflects broader 20th-century paradigm shifts (e.g., the cultural turn)

**Worked example — French Revolution:** historiography primary (liberal vs. Marxist vs. revisionist Furet vs. cultural turn) + political-history for content + intellectual-history (the disagreement maps onto Cold War politics).

## Quick Lookup — Question Word → Likely Bridge Pattern

| Word in question | Pattern hint |
|---|---|
| "fall," "collapse," "decline" | Pattern 1 (political primary, multi-causal) |
| "change," "transform," "revolutionize" | Pattern 2 (intellectual primary if technology, cultural if practice) |
| "good," "bad," "should we" | Pattern 3 (applied primary — normative) |
| "trade," "Silk Road," "exchange" | Pattern 4 (economic primary, with cultural cast) |
| "resist," "rebellion," "subaltern" | Pattern 5 (cultural primary, supplant the official narrative) |
| "war," "cause of war" | Pattern 6 (political primary, Clausewitz lens) |
| "spread," "diffusion" | Pattern 7 (cultural primary if practice; intellectual if doctrine) |
| "industrialize," "modernize," "develop" | Pattern 8 (economic primary, world-systems context) |
| "compare," "vs." | Pattern 9 (world-systems primary) |
| "disagree," "interpretation," "debate" | Pattern 10 (historiography primary) |

## Anti-Patterns

- **Don't load every wing because a question is "big."** Big questions have primary wings too. Load the primary first; let supporting wings earn their slot by what they add.
- **Don't put historiography in the supporting cast for casual-depth questions.** Schools-of-thought debates overwhelm beginners. Reserve historiography supporting cast for Learning+ depth.
- **Don't let regional-atlas substitute for thematic analysis.** Regional context grounds analysis; it does not replace the thematic wing's framework.
- **Don't escalate to a cross-domain orchestrator if a single Wan Shi Tong wing can answer.** The cross-domain bridge (philosophy, game-theory, etc.) is a heavy operation — only invoke when the wing genuinely cannot.

## When the Bridge Pattern Doesn't Match

If a question doesn't fit any of these 10 patterns:

1. Re-check whether the question has a hidden temporal register (see `temporal-register-map.md`) — temporal register often reveals which wing dominates.
2. Re-check whether the question is methodological in disguise — if "how do we know" is implicit, historiography is primary.
3. Default to political-history as primary if all else fails — it's the largest wing and most cross-cutting in the historical record.

# Intelligence And Information War — Quick Reference


## Intelligence Failures: A Taxonomy

| Failure Type | Mechanism | Example |
|---|---|---|
| **Collection failure** | Information was never gathered | Pearl Harbor (no agents in Japanese military planning) |
| **Analytical failure** | Information existed but was misread | Yom Kippur War 1973 (Israel had the intelligence but misinterpreted it) |
| **Warning failure** | Analysis was correct but ignored | 9/11 (FBI had pieces; no one assembled them) |
| **Politicization** | Analysis was shaped to fit political conclusions | Iraq WMD (2003) — intelligence was "fixed around the policy" |
| **Deception success** | Enemy's intelligence service was actively misled | Barbarossa 1941 (Stalin had ample warning but dismissed it as British provocation) |

## Formula / Pseudocode

```
Direction → Collection → Processing → Analysis → Dissemination → Decision
    ↑                                                              |
    └──────────────── Feedback / New Requirements ←────────────────┘
```

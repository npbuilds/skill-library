# Nexus Event Analyzer — Multi-Wing Synthesis

This is the most complex action skill in Wan Shi Tong's library. It handles events so large and multidimensional that no single thematic wing can contain them. The Industrial Revolution is simultaneously economic history (industrialization), political history (reform and revolution), cultural history (urbanization and class formation), intellectual history (the Enlightenment and scientific revolution), military history (industrial total war), and world-systems history (the Great Divergence). Understanding it requires all of these simultaneously.

The nexus-event-analyzer produces a multi-wing synthesis that weaves together threads from across the library into a unified analysis.

## When This Applies

- User asks about a nexus event: Industrial Revolution, French Revolution, World War I/II, decolonization, the Columbian Exchange, the Reformation, the Cold War, etc.
- User asks "how did [major event] change everything?"
- User asks about an event from multiple angles simultaneously
- User asks "what's the big picture of [transformative moment]?"

## Nexus Event Criteria

An event qualifies as a nexus if it:
1. **Spans multiple wings**: Political + economic + cultural + at least one more
2. **Is transformative**: The world after looks fundamentally different from the world before
3. **Has multi-causal origins**: Cannot be explained by a single factor
4. **Has multi-dimensional consequences**: Effects in every domain of human life

## The Analysis Process

### Step 1 — Identify the Wings

For the given nexus event, identify which wings are relevant and what each contributes:

| Wing | What it contributes to understanding this event |
|---|---|
| Political | Power structures, governance changes, revolutions |
| Economic | Material conditions, trade, production, distribution |
| Cultural | Lived experience, identity, religion, social movements |
| Military | Conflict, technology, strategy, consequences of violence |
| Intellectual | Ideas that drove or resulted from the event |
| World-systems | Structural forces, environmental factors, demographic shifts |

### Step 2 — Trace the Threads

For each relevant wing, trace its thread through the nexus event:
- **Pre-conditions**: What existed in this domain before the event?
- **Transformation**: How did this domain change during the event?
- **Consequences**: What were the lasting effects in this domain?

### Step 3 — Weave the Threads

Show how the threads interact — this is the distinctive analytical value of the nexus-event-analyzer:
- Where do the threads reinforce each other? (Economic change driving political revolution)
- Where do they conflict? (Intellectual ideals undermined by military reality)
- What feedback loops exist? (Industrial production enabling total war enabling further industrialization)
- What is the sequence? (Which threads moved first, which followed?)

### Step 4 — Synthesize

Produce a unified analysis that no single wing could generate alone.

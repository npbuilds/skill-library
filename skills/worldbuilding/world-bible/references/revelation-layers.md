# Revelation Layers

Maps the nested truths of the world. Each major element can have up to four layers of truth,
where deeper layers recontextualize everything above them.

> Design reveals **backward**: start with the deepest truth, then build the layers of
> misunderstanding on top. The reader experiences them top-down; you design them bottom-up.

## How to Use This Document

For each major world element (the fantasy system, the central conflict, the true history, key
civilizations), map what's believed vs. what's true:

```
Element: [Name]
├── Layer 0 (Surface): What most people believe
├── Layer 1 (Cracks): What doesn't add up
├── Layer 2 (Hidden): What a few people know
└── Layer 3 (Deep): The foundational truth
```

## The Revelation Spiral

Layers are static — they map what's true at each depth. The spiral is dynamic — it maps how understanding *moves* through those layers over time.

A spiral means the narrative returns to the same element repeatedly, each time revealing a deeper layer. But unlike a simple sequence of reveals, each return **recontextualizes everything the reader experienced since the last visit**.

### How the Spiral Works

```
Visit 1: Reader sees Layer 0 (surface belief)
   ↓
   ... other events happen, informed by this belief ...
   ↓
Visit 2: Reader sees Layer 1 (the cracks) — now re-evaluates Visit 1
   ↓
   ... events continue, now tinged with doubt ...
   ↓
Visit 3: Reader sees Layer 2 (hidden truth) — recontextualizes BOTH Visit 1 and Visit 2
   ↓
   ... the reader is now watching characters who still believe Layer 0 ...
   ↓
Visit 4: Layer 3 lands — everything transforms
```

The power of the spiral is **dramatic irony**: after Visit 2, the reader knows more than the characters. After Visit 3, the reader is watching people act on beliefs they know are wrong. After Visit 4, even the reader's assumptions are overturned.

### Spiral Design Principles

1. **Each visit must stand alone.** The surface story should be satisfying even if no deeper layer is ever revealed. If the plot doesn't work at Layer 0, no amount of reveals will fix it.
2. **Space between visits matters.** Too close and the reveal feels rushed. Too far and the reader forgets the earlier context. The ideal gap is long enough for the reader to build assumptions on the previous layer.
3. **Not everything spirals.** Most world elements stay at Layer 0 — that's fine. Reserve the spiral for 2-3 elements that carry the thematic weight of the story. Overusing it dilutes the impact.
4. **Artifacts can mark spiral positions.** A Layer 0 artifact about the same subject as a Layer 2 artifact creates the spiral effect when the reader encounters both. The artifact system is the spiral's engine.

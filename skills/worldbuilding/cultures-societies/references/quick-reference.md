# Cultures Societies — Quick Reference


## Quick Reference

| Pattern | Mechanism | Tends to Form When |
|---------|-----------|-------------------|
| Autocracy | Single ruler, authority flows down | Military threat requires unified command |
| Oligarchy | Small group of elites | Wealth or access concentrates in few hands |
| Theocracy | Religious authority governs | Fantasy system is channeled through religious institutions |
| Council/Republic | Elected or appointed representatives | Multiple power centers must negotiate |
| Tribal / Clan | Kinship-based authority | Population is small or decentralized |
| Anarchy / Network | No formal authority, emergent order | Resources are distributed, communication is fast |

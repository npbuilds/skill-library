# Build Sequences

Canonical build orders for common worldbuilding operations.

## Full World — From Scratch

The recommended order when building a world with no existing material.

### Phase 1: Foundation (world-bible)
1. Scale and physics
2. The fantasy system (source, cost, limits, access)
3. Resources and scarcity
4. Communication and travel constraints
5. Tone and atmosphere

### Phase 2: Geography (world-bible)
1. Physical world shape (continents, oceans, climate zones)
2. Biomes and ecology
3. Resource distribution
4. Natural barriers and corridors (these shape everything that follows)

### Phase 3: Peoples (world-bible + naming-system)
For each civilization:
1. Relationship to geography (coastal, mountain, nomadic, etc.)
2. Relationship to the fantasy system (who has access, what it costs them)
3. Core values and social structure
4. Sound palette (phoneme inventory, syllable rules)
5. Generate 10 test names — read aloud for coherence
6. Place names and institutional names using the same palette

### Phase 4: Dynamics (world-bible)
1. Faction conflict web (who needs what from whom)
2. Power structure (who controls access to the fantasy system and resources)
3. Surface relationships vs. hidden realities
4. Historical context (how did things get this way?)

### Phase 5: Secrets (world-bible)
1. Layer 0 — what everyone believes
2. Layer 1 — what observant people notice
3. Layer 2 — what a few people know
4. Layer 3 — the deep truth

### Phase 6: Artifacts (lore-writer)
Start with high-impact artifacts:
1. A Layer 0 creation myth (mythic voice)
2. A Layer 0 political briefing (clinical voice)
3. A Layer 1 artifact that shows cracks in the surface story
4. A personal document from someone who suspects something (epistolary voice)

## Single Civilization — New Addition

When adding a civilization to an existing world:

1. Read all existing axioms
2. Identify geographic niche (where do they live? what do they border?)
3. Identify resource relationship (what do they have? what do they need?)
4. Identify fantasy system relationship (how does it affect them?)
5. Build naming palette
6. Define faction web connections to existing civilizations
7. Determine what they know vs. what's true
8. Write 2-3 artifacts to establish their voice

## Single Artifact — Quick Production

When the user just wants an artifact:

1. Read relevant axioms
2. Read the culture's naming palette
3. Choose voice and perspective
4. Determine revelation layer
5. Write the artifact
6. Cross-check for consistency

## Consistency Audit

When checking an existing world for contradictions:

1. Load all world-bible axioms
2. Load all artifacts
3. For each artifact, verify:
   - Facts match the axioms for this revelation layer
   - Names follow the correct culture's sound palette
   - The in-universe author wouldn't know things above their revelation layer
   - No two artifacts contradict each other at the same revelation layer
4. Report contradictions with specific references

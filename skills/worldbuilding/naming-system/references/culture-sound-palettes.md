# Culture Sound Palettes

Phonetic profiles for each civilization's naming language. Each culture gets a unique sound palette that makes its names immediately distinguishable.

> Add cultures as they're created. Follow the template below for consistency.

## Template

```
### [Culture Name]

**Identity**: [one-sentence feel — "harsh and angular" or "flowing and warm"]

**Favored consonants**: [3-5 consonants that dominate]
**Favored vowels**: [2-3 vowel sounds that dominate]
**Avoided sounds**: [sounds that never appear — these create distinctiveness through absence]
**Consonant clusters**: [allowed / avoided / specific permitted clusters]

**Syllable structure**: [CV / CVC / CCV / CVCC — the building blocks]
**Typical syllable count**: [1-2 / 2-3 / 3-4 for personal names]
**Stress pattern**: [first / last / penultimate / even]
**Permitted word endings**: [which sounds can end a word]

**Naming convention**: [patronymic / place-based / deed-based / institutional / other]
**Formal vs common**: [how names change with formality — longer? titles? different structure?]
**Historical erosion**: [how ancient names differ from modern ones in this culture]

**Sample names**:
- People: [5 examples]
- Places: [3 examples]
- Institutions: [2 examples]
- Titles: [2 examples]
```

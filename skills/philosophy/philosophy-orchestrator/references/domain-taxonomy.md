# Philosophy Domain Taxonomy

## Architecture

```
philosophy-orchestrator ("The Examined Mind")
├── logic/                            [Active]
│   ├── argument-analyst            Action — validity, soundness, fallacy diagnosis
│   ├── assumption-excavator        Action — hidden premises, unstated warrants
│   └── formal-logic                Knowledge — propositional, predicate, modal
├── dialectical-tools/                [Active]
│   ├── socratic-examiner           Action — systematic questioning
│   ├── steel-man-forge             Action — strongest opposing argument
│   ├── thought-experiment-lab      Action — construct & vary hypotheticals
│   └── dialectic-engine            Action — thesis/antithesis/synthesis
├── epistemology/                     [Active]
│   ├── evidence-evaluator          Action — evidence quality & epistemic weight
│   ├── belief-auditor              Action — belief coherence, circular reasoning
│   └── bayesian-reasoner           Action — credence updating, calibration
├── ethics/                           [Active]
│   ├── dilemma-analyzer            Action — multi-framework ethical analysis
│   ├── stakeholder-mapper          Action — affected parties, power dynamics
│   └── values-excavator            Action — implicit values, competing goods
├── decision-theory/                  [Active]
│   ├── decision-architect          Action — structure choices under uncertainty
│   ├── bias-detector               Action — cognitive bias identification
│   └── counterfactual-reasoner     Action — "what if" analysis
├── philosophy-of-science/            [Active]
│   ├── methodology-critic          Action — study design evaluation
│   ├── paradigm-analyst            Knowledge — Kuhn/Lakatos/Popper frameworks
│   └── demarcation-judge           Action — science vs. pseudoscience
└── political-philosophy/             [Active]
    ├── justice-analyst             Action — multi-lens policy evaluation
    └── rights-reasoner             Action — competing rights claims
```

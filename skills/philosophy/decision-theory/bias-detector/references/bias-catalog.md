# Cognitive Bias Catalog

Quick-reference for the bias-detector. Organized by category with debiasing strategies.

## Information Processing Biases

| Bias | One-Line Description | Debiasing Strategy |
|------|---------------------|-------------------|
| Confirmation bias | Seeking info that confirms existing beliefs | Consider the opposite; actively seek disconfirmation |
| Anchoring | Over-relying on first information encountered | Generate multiple anchors; use reference class data |
| Availability heuristic | Judging probability by ease of recall | Use base rates; ask "what data would I need?" |
| Framing effect | Different responses to identical info based on presentation | Reframe the same problem multiple ways |
| Base rate neglect | Ignoring population statistics for specific cases | Always start with "how common is this in general?" |
| Survivorship bias | Conclusions from visible successes only | Ask "where are the failures I can't see?" |
| Representativeness | Judging probability by similarity to a stereotype | Check base rates; ask "what's the actual frequency?" |
| Conjunction fallacy | Judging P(A∧B) > P(A) because the story is more coherent | Remember: adding conditions can only reduce probability |

## Decision-Making Biases

| Bias | One-Line Description | Debiasing Strategy |
|------|---------------------|-------------------|
| Sunk cost fallacy | Continuing because of past investment | Ask "if starting fresh, would I choose this?" |
| Status quo bias | Disproportionate preference for current state | Hold action and inaction to the same evidentiary standard |
| Loss aversion | Weighting losses ~2x more than equivalent gains | Reframe as portfolio-level impact, not single transaction |
| Endowment effect | Overvaluing what you already possess | Ask "would I buy this at the price I'd sell it?" |
| Present bias | Overweighting immediate vs. future outcomes | Pre-commit; use cooling periods |
| Omission bias | Preferring harm from inaction over equal harm from action | Judge actions and inactions by outcomes, not source |
| Planning fallacy | Underestimating time/cost/complexity | Use reference class forecasting; add buffer |
| Overconfidence | Excessive certainty in own judgments | Calibration training; track prediction accuracy |

## Social Biases

| Bias | One-Line Description | Debiasing Strategy |
|------|---------------------|-------------------|
| Groupthink | Conformity pressure suppresses dissent | Assign devil's advocate; anonymous input |
| Authority bias | Deferring to authority regardless of domain | Check: is this expert qualified in *this specific area*? |
| Bandwagon effect | Believing because many others believe | Ask "would I hold this view if I were the only one?" |
| In-group bias | Favoring ideas/people from own group | Blind evaluation where possible |
| Halo effect | One positive trait colors overall assessment | Evaluate dimensions independently |

## Retrospective Biases

| Bias | One-Line Description | Debiasing Strategy |
|------|---------------------|-------------------|
| Hindsight bias | "I knew it all along" after learning outcome | Document predictions before learning outcomes |
| Outcome bias | Judging decisions by results, not process | Separate decision quality from outcome quality |
| Fundamental attribution error | Others' behavior = character; own = circumstances | Apply the same explanatory framework to self and others |
| Narrative fallacy | Constructing coherent story that oversimplifies | Ask "is this narrative capturing the actual complexity?" |
| Resulting | Good outcome = good decision | A coin flip that lands heads was still a coin flip |

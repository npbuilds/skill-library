# Fallacy Taxonomy

Quick-reference catalog for the argument-analyst. Organized by category with diagnostic patterns.

## Formal Fallacies (Invalid Argument Forms)

| Fallacy | Form | Diagnostic Pattern |
|---------|------|-------------------|
| **Affirming the consequent** | If P→Q; Q; ∴ P | Concludes the cause from the effect |
| **Denying the antecedent** | If P→Q; ¬P; ∴ ¬Q | Assumes the condition is the only path |
| **Undistributed middle** | All A are B; All C are B; ∴ All A are C | Two categories share a property but aren't connected |
| **Illicit major/minor** | Syllogism where a term is distributed in conclusion but not in premises | Conclusion claims more than premises support |
| **Equivocation** | Uses a term with two meanings as if one | Ambiguous word bridges unrelated claims |
| **Affirming a disjunct** | P∨Q; P; ∴ ¬Q | Treats inclusive "or" as exclusive |

## Informal Fallacies — Relevance

| Fallacy | Pattern | Key Question |
|---------|---------|-------------|
| **Ad hominem** | Attacks the arguer, not the argument | Does the person's character actually affect the claim's truth? |
| **Tu quoque** | "You do it too" | Does hypocrisy affect the argument's validity? |
| **Appeal to authority** | "Expert X says so" | Is the authority relevant? Do experts agree? Is the claim within their expertise? |
| **Appeal to popularity** | "Everyone believes it" | Does popularity make it true? |
| **Appeal to nature** | "It's natural, therefore good" | Is naturalness relevant to the value judgment? |
| **Appeal to tradition** | "We've always done it this way" | Does longevity validate the practice? |
| **Appeal to novelty** | "It's new, therefore better" | Does newness imply improvement? |
| **Genetic fallacy** | Judges claim by its origin | Does the source determine the truth? |
| **Red herring** | Introduces irrelevant topic | Does this actually address the conclusion? |

## Informal Fallacies — Presumption

| Fallacy | Pattern | Key Question |
|---------|---------|-------------|
| **Begging the question** | Conclusion is hidden in a premise | Would someone who doubts the conclusion accept this premise? |
| **False dilemma** | "Either A or B" (when C, D, E exist) | Are there really only two options? |
| **Slippery slope** | "A leads to B leads to catastrophe" | Is each step in the chain justified? |
| **Hasty generalization** | Small sample → broad conclusion | Is the sample representative and large enough? |
| **Composition** | Part has property → whole has property | Does the property transfer from parts to wholes? |
| **Division** | Whole has property → parts have property | Does the property transfer from wholes to parts? |
| **False cause (post hoc)** | "After X, therefore because of X" | Is there actual causal evidence, or just sequence? |
| **Circular reasoning** | A because B, B because A | Can you trace the support without returning to the start? |

## Informal Fallacies — Ambiguity

| Fallacy | Pattern | Key Question |
|---------|---------|-------------|
| **Equivocation** | Same word, different meanings | Is the key term used consistently throughout? |
| **Amphiboly** | Grammatically ambiguous structure | Does the sentence have a second parsing? |
| **Accent/emphasis** | Meaning changes by what's stressed | Would different emphasis change the implication? |
| **Straw man** | Misrepresents the opposing view | Would the opponent recognize this as their position? |

## Epistemic Fallacies

| Fallacy | Pattern | Key Question |
|---------|---------|-------------|
| **Burden-shifting** | "Prove me wrong" | Who has the burden of proof? |
| **Argument from ignorance** | "No proof against, therefore true" | Is absence of evidence meaningful here? |
| **Survivorship bias** | Conclusions from winners only | What about the cases that didn't survive/succeed? |
| **Texas sharpshooter** | Pattern found after the fact | Was the pattern predicted or post-hoc? |
| **Base rate neglect** | Ignores prior probability | How common is this in the general population? |
| **Anchoring** | First number dominates reasoning | Would a different starting point change the estimate? |
| **Confirmation bias** | Seeks only supporting evidence | Has disconfirming evidence been actively sought? |

## Severity Guide

| Impact Level | Meaning | Example |
|---|---|---|
| **Fatal** | Argument cannot be salvaged without fundamental restructuring | Circular reasoning where the only support is the conclusion itself |
| **Serious** | Argument is significantly weakened but a repair exists | False dilemma — adding the missing options changes the analysis |
| **Moderate** | Argument is weakened but core reasoning may still hold | Weak appeal to authority — the claim might still be true on other grounds |
| **Minor** | Rhetorical flaw that doesn't damage the logical core | Mild ad hominem aside in an otherwise well-supported argument |

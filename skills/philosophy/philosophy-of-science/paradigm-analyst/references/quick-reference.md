# Paradigm Analyst — Quick Reference


## Kuhn: Paradigms and Scientific Revolutions

| Concept | Description |
|---------|-------------|
| **Paradigm** | Shared commitments of a scientific community: exemplars, methods, values, ontology |
| **Normal science** | Puzzle-solving within the paradigm; extending and articulating |
| **Anomaly** | Result that resists explanation within the paradigm |
| **Crisis** | Accumulation of anomalies that shakes confidence in the paradigm |
| **Revolution** | Replacement of one paradigm by another (incommensurable shift) |
| **Incommensurability** | Paradigms can't be fully compared — they define different problems, use different standards |

## Lakatos: Research Programmes

| Concept | Description |
|---------|-------------|
| **Hard core** | Unfalsifiable foundational assumptions (protected by methodological decision) |
| **Protective belt** | Auxiliary hypotheses that can be modified to absorb anomalies |
| **Progressive programme** | Makes novel predictions that are confirmed — generating new facts |
| **Degenerating programme** | Only explains anomalies post hoc — never predicts new facts |

## Popper: Falsificationism

| Concept | Description |
|---------|-------------|
| **Falsifiability** | A theory is scientific if it can be refuted by possible observations |
| **Corroboration** | A theory is corroborated (not confirmed) when it survives severe tests |
| **Bold conjectures** | Science progresses by proposing risky theories and trying to refute them |
| **Critical rationalism** | Knowledge grows through conjecture and refutation, not verification |

## Step 2 — Assess the State

| State | Indicators |
|-------|-----------|
| **Pre-paradigmatic** | No dominant framework; multiple competing schools; disagreement on basics |
| **Normal science** | Stable paradigm; active puzzle-solving; anomalies treated as solvable |
| **Crisis** | Anomalies accumulating; ad hoc fixes multiplying; practitioners losing confidence |
| **Revolutionary** | New framework emerging; converts switching; old guard resisting |
| **Post-revolutionary** | New paradigm established; textbooks rewritten; history reconstructed |

# Optionality Architecture — Quick Reference


## Reversibility Spectrum

| Decision Type | Reversibility | Implication |
|---|---|---|
| **Lateral move at same company** | High | Low conviction OK; learning move acceptable |
| **Move to comparable role at new company** | High | Low conviction OK; the option set may broaden |
| **Move to a different functional archetype** (operator → investor) | Medium | Re-entry to original archetype harder after 2+ years; needs higher conviction |
| **Move to a much smaller / earlier company** | Medium-High | Easy to return to larger; may broaden option set |
| **Move to a much larger / later company** | Low | Re-entering early-stage harder after 3+ years at scale |
| **Founding a company** | Low | Hard to return to operator role at peer level after founding |
| **Joining a board** | High | Boards rotate; commitment is bounded |
| **Geographic relocation** | Medium | Relocates back possible but personally costly |
| **Specialization deepening** | Medium-Low | Generalization back from specialist is hard |

## Quick Reference

| High path-dependence | Low path-dependence |
|---|---|
| VC partner track | Independent advisor / consulting |
| Specialty clinical academic medicine | Generalist physician |
| Founder track | Generalist operator |
| Long-tenure board seats | Episodic engagements |

## Quick Reference

| | Opens many doors | Opens few doors |
|---|---|---|
| **Closes few doors** | Top-right: clear yes | Right: defensible if conviction is moderate |
| **Closes many doors** | Top-left: high upside but risky | Bottom-left: clear no, unless very high conviction |

## Common Failure Modes

| Failure | Looks Like | Fix |
|---|---|---|
| Optimizing for next-paycheck only | Choosing the higher-base offer regardless of option effect | Add the option-set audit |
| Optionality as procrastination | Always preserving options; never committing | At some point, conviction must beat optionality |
| Ignoring path-dependence | Treating high-path-dependent careers as flexible | Recognize the regime; act accordingly |
| Misjudging reversibility | Assuming a move is more reversible than it is | Reality-check by examining who's actually moved back |
| Single-frame decision | Evaluating only on one dimension | Use the option-set frame alongside the financial and energy frames |

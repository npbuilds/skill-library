# Skill Gap Analysis — Naming What's Missing

Most career stalls are skill-gap stalls disguised as something else. The user feels stuck and blames the network, the market, or bad luck — when the underlying issue is that the target role requires capabilities the user hasn't yet built. Honest gap analysis names the gaps, then designs the smallest credible action that closes each one. The discipline is uncomfortable (it requires admitting what you don't yet have) and high-leverage (it produces concrete next moves).

## Key Concepts

### The Gap Inventory

For a target archetype, list:

| Capability Category | Specific Capabilities |
|---|---|
| **Domain depth** | Specific knowledge / skills the target role requires |
| **Operating experience** | Specific kinds of work the target role expects you've done |
| **Network depth** | Specific kinds of relationships the target role expects you have |
| **Public signals** | Specific kinds of artifacts (publications, talks, board roles) the target role expects |
| **Vocabulary fluency** | Specific kinds of conversation the target role's audience expects |
| **Pattern library** | Specific kinds of decisions / cases the target role expects you've seen |

For each, score the current state honestly (0–10) and the target state (where the role expects you to be).

### Honest Self-Assessment

The gap analysis only works if the assessment is honest. Common dishonesty patterns:

| Pattern | Looks Like | Correction |
|---|---|---|
| **Inflation** | Scoring current state generously to feel ready | Use specific evidence — what did you do, what did you produce |
| **Deflation** | Scoring current state too harshly (impostor mode) | Test by what others would say; cross-check with mentors |
| **Vague self-talk** | "I'm pretty good at investing" | Translate to specific capabilities, then score each |
| **Confusing exposure for skill** | "I've been around VC for years" | Exposure ≠ skill; what have you *done* |
| **Confusing potential for skill** | "I could figure it out" | Capability is what you've demonstrated, not what you could |

The triangulation: self-score + mentor's score + objective evidence. Where they diverge, the truth is usually closer to the most-skeptical reading.

### Smallest-Credible-Action Design

For each gap, design the smallest credible action that closes it:

| Gap Type | Smallest Credible Action |
|---|---|
| **Domain depth** | Specific course / book / case-study series; produce an artifact that demonstrates learning |
| **Operating experience** | Side project, advisory role, contribution to public work, internal stretch assignment |
| **Network depth** | Targeted outreach to 5–10 people in the archetype's network |
| **Public signal** | One flagship public artifact (essay, repo, talk) |
| **Vocabulary fluency** | Read 50 deck reviews / IC memos / board updates from the archetype's audience |
| **Pattern library** | Diligence 5 companies / structure 3 cases / shadow someone running the actual work |

"Smallest credible" matters because:
- Larger actions get delayed, then dropped
- Smaller actions are credible enough to actually move the gap
- A series of completed smallest-credible actions compounds; a list of ambitious-but-undone actions doesn't

### Gap Closure Time

Some gaps close in weeks (read a book, hold 10 conversations). Some take years (board service requires being on a board for a year+). The honest estimate of closure time drives sequencing:

| Closure horizon | Examples | Implication for sequencing |
|---|---|---|
| **Weeks** | Vocabulary fluency, basic domain reading | Front-load; cheap |
| **Months** | Public artifacts, network depth in a sector | Plan for the quarter; consistent work |
| **A year** | Operating experience in a new function, conference presence | Plan for the year; deliberate exposure |
| **Years** | Board experience, deep operating-partner credibility, founder track record | Multi-year sequencing required |

If the target role requires multi-year gap closure, the user needs to either (a) accept the timeline and start now, (b) find an interim role that compresses the gap, or (c) reconsider the target.

### What's Not a Gap

Some perceived gaps aren't actually gaps:

- **Specific credentials** (MBA, etc.) — Often unnecessary at senior levels; check what the target role actually requires by examining 20 LinkedIn profiles in that role
- **Comprehensive domain mastery** — Most targets require depth in 2–3 areas, not breadth across all
- **Perfect public artifact portfolio** — One good flagship is enough; don't over-engineer
- **A particular age / tenure level** — The role is what matters; tenure is a noisy proxy

Coach yourself against over-listing gaps. The honest inventory is shorter than the anxious inventory.

### Common Failure Modes

| Failure | Looks Like | Fix |
|---|---|---|
| Unnamed gaps | "Something's wrong but I can't say what" | Force the inventory exercise |
| Inflated current state | "I'm ready, the market just isn't matching me" | Mentor triangulation |
| Over-listed gaps | 25 gaps; impossible to close | Prune to the 3–5 highest-leverage |
| No action design | Naming gaps without smallest-credible-actions | Each gap must have a paired action |
| Big-bang action | "I'll do an MBA" | Smallest-credible action; not the biggest possible |

## Self-Coaching Track

**For your situation (MD → biotech VC/operator):**

1. **List target capabilities for your top archetype.** Use the inventory categories above. Be specific — for biotech VC associate, capabilities include: diligence-grade reasoning, cap-table literacy, portfolio-thesis articulation, deck-reading speed, IC-room presence, founder-empathy, sector-thesis depth.

2. **Self-score honestly.** 0–10 on each capability for current state. Specify the evidence — what have you actually done that demonstrates the score.

3. **Mentor-triangulate.** Share the scoring with 1–2 trusted advisors (cross-load with `feedback-loops/advisor-board`). Where they score you differently, dig in. Their reading is often more accurate than yours.

4. **Identify the 3–5 highest-leverage gaps.** Not every gap matters equally. Prioritize gaps that (a) the target role actually tests for, and (b) you can credibly close within 12 months.

5. **Design smallest-credible action per gap.** Write down: gap → action → estimated closure time → success metric. The artifact is the work.

6. **Sequence into pivot plan.** Hand off to `pivot-sequencing` for the multi-year ordering. Cross-load with `idp-and-okrs` for quarterly tracking.

7. **Honest re-assessment quarterly.** Have you closed the gap? What did you actually produce? Where did the timeline slip and why?

## Teach / Mentor-Others Track

**When coaching a junior or peer through skill-gap analysis:**

1. **Force the explicit inventory.** Mentees often have vague senses of "I'm not ready" without specifics. Walk through the inventory categories.

2. **Triangulate the self-assessment.** Mentees often inflate or deflate. Use specific-evidence questioning ("What did you do that demonstrates that?") and cross-check with their advisor reading.

3. **The "what's not a gap" reframe.** Many mentees over-list gaps. Prune. The credentialing fixation in particular needs explicit reframing.

4. **Coach toward smallest-credible.** Mentees often design large actions ("I'll do an MBA") when smaller ones would close the gap better and faster. The smaller action is harder to dismiss as ambition-theater.

5. **Closure horizons calibrate expectations.** Mentees often want to close multi-year gaps in months. Coach honest horizon estimates; they affect timing of the move.

6. **Action design produces the artifact.** A gap analysis without paired actions is theater. Every named gap gets a paired smallest-credible action, with timeline and success metric. Make this the deliverable.

## When This Applies

- Evaluating readiness for a target role
- Planning a multi-year transition
- After a 360 that surfaces unexpected gaps
- When current applications aren't converting (often gaps the user hasn't named)
- Annual review

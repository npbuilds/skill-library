# Pivot Sequencing — Quick Reference


## Direct-Path vs Sequenced-Path

| Direct-Path | Sequenced-Path |
|---|---|
| Target role exists; user has the credentials; apply directly | Target role requires capabilities user doesn't yet have; intermediate moves required |
| 6–18 month transition | 2–5 year transition |
| Single offer / negotiation | Multiple intermediate decisions, each with optionality consequences |
| Optionality not a major concern (move is committed) | Optionality preservation matters at each stage |

## Quick Reference

| Intermediate Role | What It Does for the Trajectory | Time Cost |
|---|---|---|
| **Senior operator role at a venture-backed company** (CMO, Head of Clin Dev) | Builds operator credibility VCs respect; works alongside investor-facing work | 1–3 years |
| **Founding role / co-founder** | Builds founder pattern; some firms prefer ex-founders for partner roles | 2–5 years |
| **Independent advisor (multiple boards)** | Builds advisory credibility, network, and reputation | Compounds over time |
| **EIR at a venture firm** | Direct exposure to firm operations; insider track to partner role | 6–18 months |
| **Operating partner at a venture firm** | Hybrid role; partner-adjacent without committing to full investor track | 2+ years |
| **Venture partner (part-time)** | Lower commitment; lets user maintain operating role while building VC credibility | 1–3 years |

## Quick Reference

| Horizon | Goal | Output |
|---|---|---|
| **Year 1** | Build the credibility that makes year 3 possible | Public artifacts, network depth, intermediate role |
| **Year 2** | Convert credibility into proof points | Specific roles taken, investments, advisor seats, named achievements |
| **Year 3** | Move into the target archetype | Direct conversation with target firms / roles |

## Sequence-Risk vs Pace-Risk

| Risk Type | What It Looks Like | Mitigation |
|---|---|---|
| **Sequence risk** | The intermediate role doesn't lead where you expected | Choose intermediate roles for both intrinsic value and trajectory value |
| **Pace risk** | The transition takes longer than expected; opportunity cost mounts | Set explicit pace-checkpoints; if unmet, reassess |
| **Optionality decay** | Each step closes more options; trajectory becomes irreversible | Preserve optionality early; commit late |
| **Burnout** | Multi-year sustained transition work is exhausting | Sustainable pace; rest cycles built in |

## Common Failure Modes

| Failure | Looks Like | Fix |
|---|---|---|
| Direct-path attempt for sequenced-path target | Cold-applying for VC associate roles at firms that don't take operators | Recognize the regime; design the sequence |
| No intermediate-role plan | "Eventually I'll be a VC partner" with no path | Identify viable intermediate roles |
| Side-artifact track ignored | Pivot through roles only, no public output | Add the artifact track |
| Pace-impatience | Quitting the sequence after 12 months | Honor the multi-year horizon; checkpoint at 12, 24, 36 |
| Optionality forfeit too early | First intermediate role is highly committing | Preserve optionality early in the sequence |

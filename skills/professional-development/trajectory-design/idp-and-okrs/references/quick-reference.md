# Idp And Okrs — Quick Reference


## OKR Structure for Personal Use

| Element | Definition | Example (for MD → biotech VC transition) |
|---|---|---|
| **Objective** | Qualitative, ambitious, time-bound | "By Q4, be a credible candidate for biotech VC associate roles" |
| **Key Results** | 3–5 specific, measurable outcomes | "Publish 2 thesis essays; complete 15 firm-research deep-dives; hold 30 informational conversations; receive 3 first-conversations with target firms" |

## Quick Reference

| Dimension | Organizational | Personal |
|---|---|---|
| Cadence | Quarterly typical | Quarterly or semi-annual |
| Number | 3–5 objectives per quarter | 1–3; more becomes noise |
| Public/private | Often public for alignment | Private; share selectively with mentor / advisor |
| Scoring | 0.0–1.0; 0.7 is "good" | Same scoring works |
| Stretch | Usually built in | Be honest about stretch vs base |
| Connection to incentives | Tied to comp / promotion | Tied to trajectory progress, not incentives |

## Quick Reference

| IDP Section | Content |
|---|---|
| **Current state** | Honest snapshot — role, scope, skills, network |
| **Target state** | Where you want to be in 12–24 months — role archetype, capabilities, position |
| **Skill gaps** | What you'll need that you don't have (cross-load with `skill-gap-analysis`) |
| **Growth plan** | How you'll close the gaps — projects, courses, mentors, exposure |
| **Milestones** | Quarterly checkpoints |
| **Risk and dependencies** | What could derail; what's outside your control |
| **Review cadence** | When you'll re-evaluate (typically quarterly) |

## Quick Reference

| Mode | What It Measures | When to Use |
|---|---|---|
| **Output OKR** | Things produced (artifacts, conversations, results) | When the trajectory is committed and the work is execution |
| **Exploration OKR** | Learning velocity (archetypes assessed, hypotheses tested, conversations had) | When the trajectory is genuinely uncertain |

## Common Failure Modes

| Failure | Looks Like | Fix |
|---|---|---|
| Vague objectives | "Get better at investing" | Specific, time-bound, falsifiable |
| Unmeasurable key results | "Build network" | "Hold 30 conversations with target-archetype people" |
| Too many objectives | 5+ objectives per quarter | 1–3 maximum |
| No mid-quarter check | Set in January, check in December | Monthly check-in; quarterly recalibration |
| Output OKRs in exploration phase | Forcing artifacts when learning is the work | Exploration OKR mode |
| Quiet abandonment | OKRs disappear after 2 weeks | Calendar the review; make it small enough to sustain |

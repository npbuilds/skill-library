# Resume Craft — Quick Reference


## CV vs Resume — The Core Distinction

| Dimension | Academic CV | Industry Resume |
|---|---|---|
| Goal | Record | Position |
| Length | 5–25 pages | 1–2 pages |
| Order | Reverse chronological, exhaustive | Selected; impact-first |
| Publications | All, every authorship position | 3–5 most-relevant, with role clear |
| Bullets | Often responsibility-led | Outcome-led, quantified where possible |
| Audience | Promotions committee, awards committee | Recruiter, hiring manager, VC partner |
| Read time | Reviewer-led; minutes | Skim — 30 seconds |

## One Page vs Two Pages

| Situation | Use |
|---|---|
| Operator role at startup; VC associate role | One page |
| CMO / Head of Clin Dev / SVP at growth-stage biotech | Two pages |
| Board candidacy package | Two pages, sometimes augmented with a separate one-page board bio |
| Academic-adjacent industry role | Two pages, more publication detail |

## Common Failure Modes

| Failure | Example | Fix |
|---|---|---|
| Responsibility bullets | "Responsible for clinical trial oversight" | "Owned [trial] readout including [decision]" |
| Unquantified bullets | "Improved enrollment timelines" | "Reduced enrollment timeline from 18 to 12 months by [specific change]" |
| Acronym soup | "Led GCP/ICH-compliant DSMB-overseen Phase 2b RCT" | Spell out acronyms not in target audience vocabulary |
| Junior framing | "Assisted with FDA interaction" | "Owned the FDA Type C interaction package" |
| Three pages | Tried to keep all CV content | One page if VC-target; two if exec-target; cut everything else |

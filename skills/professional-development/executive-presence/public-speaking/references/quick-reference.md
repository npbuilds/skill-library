# Public Speaking — Quick Reference


## Talk Types and Their Distinct Logic

| Type | Length | Structure |
|---|---|---|
| **Conference keynote** | 30–45 min | One big idea, structured journey, memorable close |
| **Conference panel** | 60–75 min, ~10 min per speaker | Quick intro, 2–3 sharp takes, generous to other panelists |
| **Podcast interview** | 45–90 min | Conversational, host-led; have 3–5 stories ready |
| **Fireside chat** | 30–60 min | Conversational, interviewer-led; tighter than podcast |
| **Internal all-hands** | 10–20 min | Concrete, practical, decision-relevant |
| **Investor presentation** | 20–30 min | BLUF, structured deck, questions-friendly |
| **Lecture / academic talk** | 45–60 min | Structured, methodologically rigorous |

## Quick Reference

| Section | Time | Function |
|---|---|---|
| **Hook** | 1–2 min | A specific story, image, or question that opens the audience's attention |
| **Thesis** | 2–3 min | Your one big idea, named explicitly |
| **Reasoning** | 15–20 min | 2–3 supporting arguments, each with a story or example |
| **Implications** | 4–5 min | What this means for the audience; what they should do differently |
| **Close** | 1–2 min | Memorable line; call to action; thank you |

## Delivery Mechanics

| Element | Practice |
|---|---|
| **Pace** | 130–150 words/min for keynote; 170–200 for conversation |
| **Pause** | After key points; after questions before answering |
| **Eye contact** | Rotate across audience zones (left / center / right) |
| **Hands** | Use them; don't grip the podium |
| **Voice** | Vary pitch and volume; avoid monotone |
| **Slides** | Sparse; one idea per slide; no walls of text |

## Common Failure Modes

| Failure | Looks Like | Fix |
|---|---|---|
| Multiple big ideas | Audience can't summarize the talk | Cut to one |
| Reading the slides | Speaker faces screen; reads text | Slides as visual; talk is yours |
| No hook | Opens with "I'm pleased to be here" | A specific story, image, or question |
| Over-runs | 35 min talk in 25 min slot | Time-discipline rehearsal |
| Long-winded panel | 4-min panel answer | 90-second discipline |
| No close | Talk ends with "any questions?" | Memorable close before Q&A |
| Q&A unprepared | Stuck on the first question | Pre-anticipate the 5–10 questions |

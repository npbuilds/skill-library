# Behavioral Frameworks — Quick Reference


## STAR vs CAR

| Framework | Structure | Best For |
|---|---|---|
| **STAR** | Situation, Task, Action, Result | Most behavioral questions; explicit on stakes |
| **CAR** | Context, Action, Result | Faster, lighter; good for follow-up answers and for senior contexts where the situation is obvious |

## Common Failure Modes

| Failure | Looks Like | Fix |
|---|---|---|
| Rambling | 4-minute answer | Practice with a 90-second cap |
| No ownership | "We did X" throughout | Surface what *you* specifically decided |
| Generic result | "It went well" | Quantify or name the qualitative outcome specifically |
| Missing lesson | Ends at result, no meaning | Add the 15-second close |
| Fabrication | Story is inflated or composite | Detectable in follow-up; never fabricate |

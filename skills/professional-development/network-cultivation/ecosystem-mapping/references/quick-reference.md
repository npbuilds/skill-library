# Ecosystem Mapping — Quick Reference


## Quick Reference

| Entity Type | What to Capture |
|---|---|
| **Firms** | Name, stage focus, sector focus, recent deals, fund size, vintage, geography |
| **Partners** | Name, firm, deal areas, public writing, prior career |
| **Operators** | CMOs, Heads of Clin Dev, founders — your peer cohort and one-up |
| **Advisors** | Independent advisors, board observers, scientific advisors who span multiple companies |
| **Founders** | Especially in your domain — they're often the warmest path to their investors |
| **Publications** | Substacks, newsletters, podcasts that the ecosystem reads |
| **Conferences** | The 3–5 events where the ecosystem gathers |
| **Recruiters** | Specialized executive recruiters who place into your target archetypes |

## Sources for Building the Map

| Source | What It Gives | Effort |
|---|---|---|
| **LinkedIn searches** ("biotech investor [city]") | Partner-level contacts | Low |
| **Crunchbase / PitchBook** | Deal-level data, fund metadata | Medium (or paid) |
| **Endpoints, STAT, BioPharma Dive** | Recent deals, partner moves | Low (subscribe and skim) |
| **Substack / newsletters** | Partner thinking, ecosystem narrative | Low |
| **The firms' websites** | Stated thesis, team, portfolio | Low |
| **Twitter/X lists** | Real-time ecosystem signal | Low |
| **Conference attendee lists** | Cross-section of active players | Medium |
| **Reference interviews** | Who's good vs who's loud | High (and high-value) |

## Common Failure Modes

| Failure | Looks Like | Fix |
|---|---|---|
| Too broad | "Map all biotech investors" | Narrow to a sector × stage cell |
| Stale | Built once, never updated | Add a monthly maintenance window |
| Static | Entities only, no relationships or activity | Add relationship and activity layers |
| Unused | Map built but doesn't drive outreach | Stewardship and outreach should reference the map |
| Vanity-mapped | Mapping famous partners you'll never realistically reach | Map the people you can reach — partners, principals, advisors, founders at your target stage |

# The Loom — Quick Reference

## Director Routing

| If the user asks about... | Route to |
|---|---|
| Frontier, capabilities, what's new, emergence | **Sense** |
| Vision, paradigm, possibilities, thesis | **Envision** |
| Starting, conditions, constraints, prototypes, loops | **Seed** |
| Interface, exposure, experience, pricing, value | **Surface** |
| Adaptation, amplification, pruning, learning | **Evolve** |
| Portfolio, patterns, briefing, narrative, status | **Synthesize** |

## The Loom Cycle

```
Sense → Envision → Seed → Surface → Evolve → Synthesize
  ↑                                              │
  └──────────────────────────────────────────────┘
```

Enter at any phase. Skip phases when appropriate. The cycle is a default, not a requirement.

## Initiative Lifecycle

```
seed → germinating → emerging → surfaced → evolving → mature → composted
```

Initiatives can move backward or skip. Track via `synthesize/initiative-tracker`.

## Anti-Patterns

- Over-orchestration: don't weave 5 domains when 1 suffices
- Planning without seeding: vision without prototype is fantasy
- Feature thinking: "what conditions produce this behavior?" not "add feature X"
- Premature surfacing: germinate until the signal is clear
- Consensus-seeking: The Loom decides; domains advise

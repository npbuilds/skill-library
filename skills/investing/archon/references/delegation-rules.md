## Multi-Subdomain Routing

Most real investment questions span subdomains. Analyze in dependency order.

### The Archon Loop Sequence (Full Analysis)

For comprehensive portfolio analysis, run the full loop:

**① Regime Intelligence → ② Reflexivity & Sentiment → ③ Opportunity Sourcing → ④ Risk Filter → ⑤ Construction → ⑥ Monitoring**

Each step receives the output of prior steps as context.

### Common Multi-Subdomain Sequences

**"Should I buy X stock?"**
1. Regime Intelligence → What regime favors/disfavors this type of asset?
2. Value & Quality → What's it actually worth? What's the moat?
3. Reflexivity & Sentiment → What's the consensus? Is it priced in?
4. Risk Architecture → How much to allocate? What's the stop?
5. Portfolio Construction → How does it fit the existing portfolio?

**"How should I position for a recession?"**
1. Regime Intelligence → How confident is the recession call?
2. Asset Universe → Which asset classes perform in recessions?
3. Market Microstructure → Are passive flows creating forced selling risk?
4. Risk Architecture → How to size the defensive shift?
5. Portfolio Construction → Build the recession-resilient allocation
6. Adaptive Monitoring → What signals would invalidate the recession thesis?

**"What's the best risk/reward right now?"**
1. Regime Intelligence → What regime are we in?
2. Reflexivity & Sentiment → Where is consensus most extreme?
3. Special Situations → Any overlooked structural opportunities?
4. Value & Quality → Filter for genuine value and quality
5. Risk Architecture → Stress test the candidates
6. Portfolio Construction → Size and hedge the winners

**"Is my portfolio positioned correctly?"**
1. Regime Intelligence → What regime, and is the portfolio aligned?
2. Adaptive Monitoring → Performance attribution — what's working/not?
3. Risk Architecture → Stress test against tail scenarios
4. Geopolitical Overlay → Any structural risks not accounted for?
5. Portfolio Construction → Rebalancing recommendations

**"Explain how X works"** (Educational)
Route directly to the relevant knowledge skill — no multi-step sequencing needed.

## When NOT to Delegate

Handle directly at the Archon level when:
- The question is about the Archon Loop itself or how to think about investing
- The user wants a comparison of investor frameworks (Soros vs Buffett approach to X)
- The question spans so many subdomains that sequential delegation would lose coherence — instead, build the synthesis at the orchestrator level while referencing subdomain knowledge
- The user is in the early stages of learning and needs the big picture before details

## Escalation Rules

- If any subdomain returns a finding that contradicts another subdomain's finding, the Archon presents both with explicit reasoning about which to weight more heavily — it does NOT silently pick one
- If regime classification is contested (transition period), present conditional analyses: "If we're in late-cycle, then X; if recession has begun, then Y"
- If risk analysis reveals that an opportunity fails the risk filter, report this honestly even if the opportunity is compelling — the Archon never overrides Risk Architecture to chase returns

# v0.2 Improvement Spec — Strategist Suite

Output of the Spelunker deep-dive (commit `f496f7c` baseline). Synthesizes 5 angle-specific agents, Archon's six-framework lens, and an adversarial refutation pass. Format: concrete edit list with cited evidence. Implementation is a *separate* approval — this spec is the deliverable.

## Quick read

- **3 kills, 4 conditional, 1 ready for paper validation.**
- **Zero MCP-level blockers.** Every Robinhood field strategists assume was Confirmed via live MCP calls.
- **Three real architectural gaps to close:** (1) directors are routers, not output contracts; (2) no suite-level position cap; (3) no inter-strategist coordination on the same symbol.
- **The biggest finding by impact** is that three of the eight strategists fail the literature-evidence floor and should not be promoted to live in their current form.

## Kill-list — do not promote to live

These strategists keep their library entries (analyst-mode useful) but should be marked `mode: review` permanently and excluded from any autotrader cron.

### day-trader — KILL
**Rationale:** The strategy's own author, **Toby Crabel**, has publicly stated the Opening Range Breakout edge has vanished since 24-hour markets normalized. (Source: BigGo / Crabel interview surfaced by Agent F adversarial pass.) The strategist uses 1:1 R/R by formula (`target = OR-high + (OR-high - OR-low)`, `stop = OR-low`); breakeven requires >50% win rate before slippage, which no current evidence supports on mega-caps post-2020. Tudor Jones framework lens reinforces: 1:1 R/R is below the 2:1 floor.

**Spec edit:** Add `do_not_promote: true` to frontmatter with `kill_reason: "crabel_obsolescence_post_2020"`. Keep SKILL.md for educational value.

### earnings-event-trader — KILL
**Rationale:** PEAD (post-earnings announcement drift) literature documents the effect on **small-caps**, not mega-caps. The strategist's allowlist is entirely mega-cap. Agent A: "In mega-cap stocks, PEAD is minimal because institutional traders rapidly incorporate information." The thesis targets a universe where the effect is absent. Wrong-universe is a thesis-level problem, not a parameter tune.

**Spec edit:** Add `do_not_promote: true` with `kill_reason: "wrong_universe_pead_absent_mega_cap"`. Optional v2 rework: rebuild for small-caps with a microstructure overlay (out of scope here).

### reflexivity-trader — KILL
**Rationale:** Load-bearing on `reflexivity-sentiment`, which is a router not an output contract. Per Agent E, JSON-mode prompts may fail 5-10% of ticks without defensive parsing. Per Agent A, no published rule-based reflexivity system exists. The allowlist is the highest-vol-narrative cohort (SMCI, MSTR, PLTR, COIN) — precisely the names where a misclassified "validation → exhaustion" turn is the most expensive. Sizing 33% × confidence on an LLM-derived signal is asymmetric risk.

**Spec edit:** Add `do_not_promote: true` with `kill_reason: "uncontracted_signal_max_reflexive_cohort"`. Skill remains useful in Claude Code analyst mode for thesis exploration.

## Conditional-list — needs specific changes before paper validation

### rebalancer — CONDITIONAL
**Gate to clear:**
1. Raise `drift_thresholds.normal` from `0.025` → `0.05`. On a $1k account, 2.5% drift triggers ~$25 trades that bid/ask + fees overwhelm.
2. Add cross-strategist collision guard: skip rebalance tick if `dca-investor` already fired in the same session (read DCA's state file in pre-flight).
3. Add `min_trade_size_usd: 5.00`. Rebalance intents below this threshold get dropped with `reason: below_min_trade_size`.

**Why conditional, not ready:** The strategy is sound; the parameter calibration is wrong for the account size.

### swing-trader — CONDITIONAL
**Gate to clear:**
1. Add `stop_loss_pct: 7.0` to frontmatter. Phase 4 must emit a sell intent when `(current_price - entry_price) / entry_price < -0.07`. Tudor Jones floor.
2. Shrink allowlist to broad ETFs only: `[SPY, QQQ]`. Drop single-name mega-caps (AAPL, MSFT, NVDA, GOOGL, META, AMZN) — they exhibit momentum-not-mean-reversion on bad news, and 2025 RSI mean reversion is already degrading (QuantifiedStrategies cited by adversarial agent).
3. Make `market-microstructure` a **gate**, not a `notes` log. When microstructure response includes `"momentum_dominant"`, set conviction to 0 and skip all entries this tick (not 0.5× conviction).

**Why conditional:** RSI mean reversion has Likely empirical support but the strategist's specific parameter choices have weak defenses.

### macro-overlay-trader — CONDITIONAL
**Gate to clear:**
1. **Collapse to static All-Weather.** Set `quadrant_targets` to a single fixed weight set: SPY 0.30, GLD 0.075, TLT 0.40, IEF 0.225 (Bridgewater's published All-Weather mix). This is the empirically supported variant.
2. Remove the dynamic quadrant rotation logic — its specific edge isn't proven and regime classification is noisy. The strategist becomes a target-weight rebalancer to a single fixed target.
3. Re-add dynamic rotation only after: (a) regime-intelligence has a typed contract with hysteresis (no quadrant flips on a single tick); (b) backtest against static All-Weather shows ≥1.0 Sharpe edge.

**Why conditional:** Static All-Weather Likely works; the dynamic version is the speculative addition.

### options-strategist — CONDITIONAL (stays analyst-only)
**Gate to clear:**
1. Add `min_account_value_usd: 10000` to frontmatter. CSP collateral math doesn't fit a $1k account.
2. Permanently disallow promotion to live in `autotrader` profile (already enforced by `profile_compatibility` but make it explicit in the spec).
3. Live promotion only valid in a future `options-trader` Hermes profile with its own SOUL, AND on an account with `account_value >= 10000`.

**Why conditional:** The strategy is empirically supported (Agent A: Likely) but the $1k account makes the slippage/fee math hostile. Wait until account size justifies the contract economics.

## Architectural changes (apply regardless of which strategists promote)

### A. Suite-level position cap (Agent C — critical)

Add a profile-level config at `~/.hermes/profiles/autotrader/suite.yaml`:

```yaml
suite:
  max_total_position_pct_per_symbol: 60     # of buying_power, summed across strategists
  inflight_symbols_mutex: true               # any strategist whose intent touches an inflight order skips
  enforcement: hard                          # abort intent, not whole tick
```

Executor pre-flight gains a new phase **1.7 (Suite cap check)**:

```
for each intent in candidate set:
    current_positions[intent.symbol] from get_equity_positions
    suite_held_pct = sum(positions[intent.symbol].notional / account_value)
    proposed_pct = intent.notional_usd / buying_power
    if suite_held_pct + proposed_pct > suite.max_total_position_pct_per_symbol / 100:
        drop intent: status="skipped", reason="suite_cap_breached"
```

### D. Inflight-symbol mutex

Executor maintains a per-profile `inflight_symbols` set keyed on `account_lock`. Populated by every `place_equity_order` until the order reaches a terminal state (`filled` or `cancelled`). Any strategist whose intent touches a symbol in the set gets `aborted: symbol_locked_inflight; retry_after: <next_tick>`. Prevents same-tick race between DCA buy and rebalancer sell on SPY.

## Director updates (Agents D + E)

Five directors invoked by strategists' Phase-2 JSON-mode prompts need surgical additions. All are backwards-compatible — existing conversational use is unaffected.

### Universal: "Structured Response Mode" addition

Append this section to each director's SKILL.md:

```markdown
## Structured Response Mode

When the calling prompt contains the literal string "respond ONLY with JSON",
emit a single valid JSON object matching the requested schema EXACTLY. Do not
add prose, reasoning, or explanation — the calling strategist parses the response
as pure data. Schema MUST be honored exactly; missing required fields constitute
a failed contract.

Existing conversational behavior is unchanged when the activation phrase is absent.
```

Apply to: `regime-intelligence`, `reflexivity-sentiment`, `risk-architecture`, `value-quality`, `market-microstructure`, `portfolio-construction`, `asset-universe`, `special-situations`.

### Defensive parse layer (strategist-side, not executor-side)

Per Agent E recommendation. Each strategist that consumes director JSON wraps the call in a try/parse with neutral-stance fallback:

```python
response = invoke_director("<name>", phase2_prompt)
try:
    data = json.loads(response)
    if not all(k in data for k in required_fields):
        log("malformed director response — missing fields"); return neutral_stance
except JSONDecodeError:
    log("malformed director response — not JSON"); return neutral_stance
```

`neutral_stance` for each strategist is documented in its `references/decision-rules.md`. For most: `{"symbol": null}` → skip entries this tick.

The autotrader profile runs multiple strategist skills. To prevent over-commitment:

## New verification gates

Beyond the v1 plan's 10 gates, add 5 more once architectural changes land:

11. **Suite-cap enforcement** — load dca-investor + rebalancer simultaneously, force both to want to buy SPY same tick. Executor must trim or drop the second intent with `status: skipped, reason: suite_cap_breached`. Verify `tick_decision` from both strategists reflects the cap.

12. **Inflight mutex** — DCA tick fires SPY buy with `mode: live` in cron. Before the order fills, rebalancer ticks and wants to sell SPY. Executor must reject rebalancer's SPY intent with `aborted: symbol_locked_inflight`. (Test against paper account; cancel order immediately after.)

13. **Priority ordering** — both rebalancer and dca-investor fire same tick on first-of-month Monday. Verify rebalancer's intents process first (sells before buys) per the priority field.

14. **Collision guard** — set `collision_guards: [dca-investor]` on rebalancer. Run DCA tick, then immediately run rebalancer. Rebalancer should emit `tick_decision` with `actions: []` and `notes: "collision_guard: dca-investor fired at <ts>"`.

15. **Kill-list refusal** — try to flip a kill-listed strategist (`day-trader`) to `mode: live`. The executor or a pre-flight check should refuse on `do_not_promote: true` regardless of frontmatter `mode`.

## What this dive did NOT do

- **No backtests.** Recommendations to "backtest before promote" remain user actions, not dive deliverables.
- **No regime-intelligence redesign.** The dive surfaces the contract gap; a separate effort closes it via the Structured Response Mode addition (low cost).
- **No new strategists added.** The 8 are the 8. Recommendations are kill/conditional/ready, not "build a new one."
- **No cross-profile coordination.** If/when an `options-trader` profile exists alongside `autotrader`, they don't coordinate. Out of scope.
- **No tax-aware coordination.** Wash sale risk between DCA and rebalancer on SPY same week is real but deferred to v0.3.
- **No correlation-cluster caps.** SPY + VTI + VOO are ~95% correlated; the per-symbol suite cap doesn't capture this. v0.3.

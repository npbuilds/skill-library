# Selling Deaccessioning — Quick Reference


## Quick Reference

| Channel | Discovery | Commission | Discretion | Best For |
|---|---|---|---|---|
| **Public auction** | Highest | High (10–25% seller's + ~25% BP funds the price discovery) | Lowest (public record) | Iconic / category-defining items with strong demand depth |
| **Dealer / private treaty** | Medium | Lower (10–15% typical, sometimes 5–10% on big-ticket) | High (private, off-market) | Items the user wants to move without public attention; relationships matter |
| **Direct / peer-to-peer** | Lowest | None (but legal/escrow costs) | Variable | Lower-value items, specialist communities, items where the user has the buyer network |

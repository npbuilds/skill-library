# Luxury Handbags — Quick Reference


## Blind Stamp Era Codes

| Era | Stamp Style |
|---|---|
| Pre-1971 | No date stamp |
| 1971-1996 | Single letter in a **circle** (A through Z, then restart with shapes around the letter) |
| 1997-2014 | Single letter in a **square** (A through Z) |
| 2015-present | New format — letter in a separate position; not always shape-bounded |
